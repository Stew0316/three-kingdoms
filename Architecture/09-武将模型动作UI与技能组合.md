# 武将模型、动作、UI 与技能组合

更新日期：2026-10-24。状态：模型/动作/UI/技能定义分离与运行时换装子集已实现。具体武将装备、姿态参数和验证历史见 [角色制作记录](../Demand/Content/Records/CharacterCompositionHistory.md)。

## 1. 组合与所有权

| 对象 | 职责 | 换技能时的行为 |
| --- | --- | --- |
| `CombatantConfig` | 身体基础属性；冒险成长使用人物自己的副本 | 不随技能替换身份或身体定义 |
| `CharacterModelConfig` | 图集、固定骨架绑定、采样、挂点、武器与绘制顺序 | 保留角色自身结构 |
| `CharacterAnimationConfig` | 姿态、动作曲线、握持与归一化阶段 | 按当前角色的动作解释技能语义 |
| `CharacterPresentationConfig` | 模型、动画和表现组合 | 不决定伤害和技能消耗 |
| `CharacterUiConfig` | 角色名称、头像、主题等身份资料 | 不随借入技能改变 |
| `CombatActionConfig` / `PassiveConfig` | 独立只读技能定义与稳定 ID | 规则、数值和图标来自当前装备 |
| `SkillLoadoutConfig` | 默认技能装配 | 不被运行时换装改写 |
| `SkillLoadoutRuntime` | 本单位装备与按 ID 冷却 | 实例独占，不共享运行状态 |
| `AttackSpec` | 当前施法规则快照 | 开始后不被换装或共享资源变更改写 |

角色场景位于 `Components/Characters`，配置实例位于 `Resources/Config/Characters`，独立技能位于 `Resources/Config/Skills`。`HeroCatalog` 负责寻址装配和必要只读资源引用；`HeroSelection` 保存选择，冒险人物状态由会话拥有。

## 2. 输入槽、动作语义与技能身份

`CombatAction` 是输入槽，`CombatMotion` 是动作语义，`SkillId` 是技能身份，三者不能互相替代。当前四主动槽为 Dash/Sweep/Skill3/Skill4，普攻与闪避独立，默认键位与图标见 UI 系统。技能换槽不应改变自身冷却、名称与效果。

规则时间决定前摇、生效和后摇；动画按归一化阶段采样。新投射物、引导或魅惑必须实现对应规则处理器，不能只新增动作枚举就宣称支持机制。被动与装备容量的长期方案见 [技能设计](SkillDesign.md)，不在这里提前锁死。

## 3. 模型与动作配置合同

现有模型使用固定人形业务关节，不是任意骨架。支持独立头图、武器裁剪多边形、手臂原图锚点与双持配置；具体采样窗口和身体尺寸属于角色内容。

武器握点落在可握位置，骨长和关节弯曲支路由模型与动作约束保持；镜像不能随目标跨轴导致翻肘。双持是角色表现能力，不是某个技能身份分支。动作途经姿态和副手接柄曲线负责自然动作衔接，不改变判定时钟。

技能互换保留外观与动作身份，并允许玩法组合自由发展；这不构成“某角色只能装备某流派”的限制。需要另一种武器结构或新动作时，应补齐表现能力和显式兼容规则。

## 4. 当前换装接口

默认装备通过 `SkillLoadoutConfig` 资源编辑；运行时调用 `TryEquipSkill(slot, definition)` 或 `TryEquipPassive(index, definition)`。

- 当前仅空闲/行走且没有进行中的反击允许替换；攻击、闪避、受击、死亡或结算状态拒绝。
- 同一单位的主动槽按 SkillId 去重，被动列表同样去重；稳定 ID 非空且唯一。
- 卸下技能继续保留并推进实例冷却，装回不刷新；共享定义不导致不同单位共享冷却。
- 修改不写回默认资源，不清除已有状态，不修改正在施法的快照。
- 当前只能替换已有被动位置；未实现任意增减槽位、通用配装 UI 或装备存档。

## 5. UI、AI 与扩展

HUD 从角色 UI 配置读取身份，从实时装备读取技能名称、图标、说明和冷却。按键映射由共用输入设置提供，不把默认键名写死在技能定义中。

当前 AI 根据装备的动作语义、范围、位移和冷却选择技能，保留旧控制器类名用于兼容。此能力只覆盖当前技能子集，不能推断已支持治疗友军、魅惑或复制的决策。

新增角色先配置模型与动作，再装配 UI、属性和默认技能；复用控制器与规则入口。验证本角色自然动作，以及借入其他技能后的伤害、冷却、反馈与状态隔离。具体角色制作清单放在 Demand，通用检查方法见 [制作管线](07-制作验证管线与演进路线.md)。
