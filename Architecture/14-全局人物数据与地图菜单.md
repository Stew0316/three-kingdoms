# 全局人物数据与地图菜单

更新日期：2026-10-24。状态：以下会话数据和共用导航已接入；具体地图、开放状态、坐标与调参见 [导航内容记录](../Demand/Content/Records/NavigationHistory.md)。

## 数据所有权

`AdventureSession` 是现有全局入口，不新增第二份管理器。

| 数据 | 唯一来源 | 生命周期 |
| --- | --- | --- |
| 移动、镜头、小地图与时间参数 | `Settings` / `GameSettings` | 全局只读定义 |
| 内容服务与成长参数 | 现有内容配置 | 全局只读定义 |
| 人物属性、当前生命、成长与移动倍率 | `Characters[稳定 ID]` / `CharacterAttributes` | 冒险会话 |
| 任务、物品、交互状态 | `Progress` | 会话与版本化存档 |
| 地图节点、路线与场景引用 | `Atlas` / `WorldAtlas` | 全局只读内容 |
| 冷却、受击、碰撞、表现 | 当前场景的 `Combatant` | 场景或遭遇 |

人物首次出现时复制基础资源，冒险场景引用同一人物对象；`Health` 转发唯一人物生命，菜单读取同一数据。独立演武沙盒使用可重置基线，不能把冒险成长错误应用到其他人物。

存档保存人物 ID 关联的普通数值与进度，当前生命仍沿用生命比例字段。旧档缺省移动倍率有默认值，Node、资源字典和临时战斗状态不序列化。

## 移动与显示

普通移动速度由基础徒步/骑乘速度、人物倍率与状态倍率组合，经加减速和物理移动处理。普通移动倍率不自动修改攻击位移、闪避或击退。模态交互开始时清除移动意图，关闭菜单要求释放残留攻击输入，避免确认操作穿透。

镜头缩放改变观察范围，不改变骨骼尺寸或碰撞。具体倍率选项、镜头缩放和小地图比例属于配置与内容记录。

## 暂停与共用界面

`AdventureMenu` 在各场景装配为 CanvasLayer，记录打开前暂停状态，只恢复自己拥有的暂停；与选将、结算和对话维护明确优先级。快捷道具与背包读取同一库存；坐骑等操作仍通过当前地图资格判断。

`LocalMinimap` 读取当前场景真实几何与角色位置，显示方向、观察范围和必要标记。世界图、本地导览与局部小地图职责分开，不复制一份独立世界进度。

## 世界图与扩展

`WorldAtlas` 从 `Resources/Config/WorldMap/town-map.json` 读取稳定地图 ID、底图坐标、路线折点和预留场景引用。地图查看支持选点、邻接路线高亮、缩放与拖动；图像坐标和路线描点属于内容，不是物理寻路网格。

登记节点不代表该地图已建成，也不代表绑定路径后自动具备传送。具体城池位置与剧情归 Drama/内容；开放入口要经过场景、入口、通行与保存验证。导出包含对应 JSON，避免配置文件漏包。

当前仍是显式切图与可扩展世界图目录，不是已完成的通用 `WorldGraph`。验证关注数据唯一性、暂停所有权、跨图状态、缺省存档与未开放节点反馈，结果见 [内容实现索引](../Demand/Content/ImplementationIndex.md)。
