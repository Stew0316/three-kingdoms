# 全局人物数据与地图菜单

日期：2026-10-21。状态：已接入城市、暗窟和演武场；天下图为可扩展城池目录，尚未制作其他城市场景。

## 数据所有权

沿用现有 `AdventureSession` Autoload 作为全局入口，不再添加第二个全局管理器。

| 数据 | 唯一来源 | 生命周期 |
| --- | --- | --- |
| 移动加减速、倍率限制、镜头和小地图参数 | `Settings` → `Resources/Config/World/game-settings.tres` | 全局只读配置 |
| 城镇服务与成长参数 | `Config` → `first-city.tres` | 全局只读配置 |
| 冒险人物基础属性、当前生命、伤害倍率、移动倍率 | `Characters[人物稳定 ID]` → `CharacterAttributes` | 整个冒险会话 |
| 任务、货币、物品、点火、倍率选择 | `Progress` | 内存进度及版本 1 JSON 存档 |
| 城池、陆路水路、折线与未来场景入口 | `Atlas` → `Resources/Config/WorldMap/town-map.json` | 全局只读内容 |
| 技能冷却、受击状态、碰撞节点、表现节点 | 当前场景的 `Combatant` | 切图重建 |

`CharacterAttributes.Config` 只在该人物首次出现时复制武将基础资源。城池、洞窟和冒险试炼使用同一份人物对象与同一份属性资源，不在每次进图重新累加训练收益。`Health` 直接转发读写唯一人物的生命，保留原有受伤/死亡信号。人物页也读取该对象。

普通冒险玩家目前为 `core:lubu`，徒步统一使用首城配置的 125 像素/秒；进入冒险试炼也保持该速度。`--arena` 独立演武仍是可重置练习沙盒，使用武将内容基线，不修改冒险人物和存档；选择其他武将不会把吕布成长错误应用给对方。

倍率以 `CharacterMoveRates[人物 ID]` 保存，旧档没有该字段时默认 1。已有训练、任务、物品、生命比例等字段兼容。当前生命在存档中仍以原生命比例字段保存，场景节点、字典中的 Godot 资源及短时战斗状态不序列化。

## 移动与显示

普通移动目标速度为：徒步速度或骑乘速度 × 人物倍率 × 状态减速倍率。`MoveToward` 按加速度或制动力和物理时间步渐变，之后调用 `MoveAndSlide()`。普通变速不改攻击/闪避位移和击退公式。

人物页提供 0.5、1、1.5、2 倍。打开菜单、交互对话等立即清除行走速度，防止制动滑入目标；菜单暂停期间不推进物理或战斗计时。关闭菜单需要先释放攻击键，避免确认点击变成一次攻击。

通过城市 0.72、洞窟 0.8、演武场 0.8 的镜头缩放减少人物画面占比，保留人物、坐骑、建筑、武器范围和碰撞之间的世界比例。没有压扁人物骨骼或改变其物理尺寸。

## 共用界面

`AdventureMenu` 为各场景装配的 CanvasLayer，`Esc` 打开右侧栏；分页内 `Esc` 返回侧栏，再按关闭。`M` 直接切换天下图，`I` 切换背包；侧栏包含地图、物品栏、人物、背包、坐骑，并追加设置及最底部的退出确认。底部状态栏、按键映射及昼夜接入见 [后续架构](15-人物底栏按键设置与昼夜循环.md)。

菜单独立记录打开前的暂停状态，关闭只恢复自己持有的暂停。与战斗选将和结算面板互斥，打开时隐藏旧暂停遮罩。普通 NPC 对话使用原对话层，Esc 优先关闭对话。

物品栏先作为快捷道具页，背包展示全部持有物及兵书，二者共享 `Progress.Items` 和任务所得，不复制库存。坐骑页在城市可调用既有上/下马；洞窟与演武不可上马。

`LocalMinimap` 常驻左下角，固定朝北、玩家居中、箭头标明朝向。当前共用底栏使用70×70圆形地图。全局 `MinimapWorldUnitsPerPixel=3.2` 与骑乘值 `4.2` 再乘 `MinimapRangeMultiplier=2`，实际为每地图像素对应6.4/8.4世界像素，观察距离比原比例翻倍（用户示例1:100→1:200）；该倍率不影响菜单内本地总览的自动适配。城市建筑/城墙读取实际碰撞矩形，洞窟从 `CaveLayout.IsFloor` 绘制，演武显示敌人。天下图内另有本地全景导览。

## 天下图与后续城池

`Town.png` 直接作为参考底图，保留其地图布局。`WorldAtlas` 在 JSON 中独立登记 42 个城市的稳定 ID、图像像素坐标、预留 `ScenePath`，以及陆路/水路和中间折点。点击或下拉选城显示相邻城市与路线高亮，支持滚轮缩放、拖动、全图复位。

底图已经绘有道路，因此默认全图沿用原图道路，独立折线用于选中高亮；折点是人工按参考图描记的游戏内容，不是地理测绘或自动寻路网格。未开放城市标注“待建设”，不提供无目标场景的传送按钮。

槐安为现有虚构初始区域，其对应天下位置等待 `Drama` 决定，界面不把玩家伪标在某座历史城池。后续先确定城池与剧情，再实现本地场景、入口和可玩路线，最后绑定该节点的 `ScenePath`；填场景字段本身不会自动完成场景切换逻辑。

Windows 导出明确包含 `Resources/Config/WorldMap/*.json`，避免原始内容文件在导出时被遗漏。
