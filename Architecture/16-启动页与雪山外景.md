# 启动页与雪山外景

日期：2026-10-24。需求与验收见 [本轮记录](../Demand/Prompt/2026.10.24-启动页与城外雪山.md)。

## 启动流程

`GameEntry` 先创建 `StartupSplash` 并提交画面，再通过 `ResourceLoader.LoadThreadedRequest` 逐项加载目标场景及城市外景贴图，逐帧查询完成状态。从启动页出现起最短展示一秒，加载不足一秒则补足，超过一秒就绪后立即切换，不追加等待；资源尚未就绪时继续等待；资源失败留在黑底页显示中文错误。人物场景交由目标场景正常创建，避免 4.7.1 下额外预载该场景产生的原生资源清理警告。切换前把覆盖层交给根节点，覆盖层订阅 `SceneChanged` 和首个绘制帧后释放，错误与退出时明确解除订阅，避免黑屏或地图装配过程外露。进入演武或洞窟时不预载无关的城市雪山贴图。

`StartupSplash` 使用独立 CanvasLayer，不接受游戏交互。中文字号 30、英文字号 17、工作室字号 24，项目逻辑分辨率为 640×360，默认窗口为两倍显示。致谢文字组居中、品牌横排底部居中。原始 `BaseSource/logo-owl-dark-v2.png` 不修改，AtlasTexture 采样猫头鹰区域 `(225,145,805,705)`，`StartupLogo.gdshader` 去除深色底；名称由引擎显示为 `stew studio`。引擎自带启动图关闭、背景改为黑色。

普通启动、`--arena`、`--cave` 均经过启动页；已有测试参数保持直接路由。`--startup-snow-test` 专项验证真实启动流程，沿用 AdventureSession 的测试存档隔离。返回城市不重播启动页。

## 外景分层

| 文件 | 职责 |
| --- | --- |
| `SnowMountainLayout` | 外景范围、原画矩形、山脚入口和上下路岸坐标。 |
| `CityMap.Exterior` | 根据路岸构建路外封闭多边形和山脚终止碰撞。 |
| `SnowMountainExterior` | 独立雪山 Sprite、生成草地地面、生成岩脊路肩。 |
| `ColdMeadow.gdshader` | 活草向稀草、冻土、斑驳雪地连续过渡，路外略压暗。 |
| `FirstCity` | 添加山脚查看点；靠近东门逐步放开镜头边界，靠近雪山拉远并向北观察。 |
| `LocalMinimap` | 同一份路带多边形与入口标记；本地总览使用扩展地图范围。 |

收尾调整：小地图与本地导览使用雪山透明原画呈现实际轮廓，不再把山体画成矩形；山脚终止碰撞不绘制成穿越雪山的长直线。山脚镜头缩放 0.44，保留完整山顶。

城内 60×40 TileMap、五屋、五名 NPC 和旧驿道保持原有布局。东侧城墙只在 y=242–320 开门，演武场继续通过东门交互进入；直接沿路行走则到雪山。地图外景范围 x=932–2304，y=-704–640；背景地面留额外余量，盖在城内 TileMap 下方。

雪山是单张透明地标原画，但草路有独立真实地面与物理边界，并非把整张关卡做成可任意穿行的背景图。人物和坐骑均只能走路带；山脚 `(1650,0)` 可查看，尽头 y=-12 阻挡进入，其他山体与外景均不可进入。当前没有雪山室内场景、传送或新任务，不改存档结构。

## 验证

`--startup-snow-test` 检查实际启动、文本、覆盖层释放、徒步往返、六段连续碰撞扫掠、两侧封闭、山脚终止、入口对话及最快坐骑的通行/阻挡，并通过真实移动输入连续走完东门到山脚、骑快马原路返回。进入真正的本地导览再截图，日间/夜间、入口、小地图与全景共八张。`--city-test` 中原本朝东门撞墙的检查移至完整东墙段 y=400，仍检查同一骑乘碰撞行为。
