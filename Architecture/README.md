## 状态约定

- **已确认设计**：用户认可的方向，不等于代码已存在。
- **提案**：待验证的结构、接口或参数，不作为现有能力承诺。
- **已实现子集**：已有代码入口，必须同时说明缺口；详细实机结果另见 Demand。
- **已验收**：仅用于有对应环境与证据的具体交付记录，不凭文档整理重新宣称验收。
- **历史记录**：在 [迁出记录索引](../Demand/Content/Records/README.md) 查阅，原日期中的“当前”不能覆盖最新规范。

## 扩展性判断

1. 普通新技能通过定义、效果与表现配置组合；特殊机制通过受控扩展点进入统一结算。
2. 玩家、敌人和友军共用目标、技能、伤害与状态规则，资格差异显式表达。
3. 新内容不依靠核心算法中的人物名、地图名或 DLC 名称分支。
4. 场景、表现和存档拥有清楚的生命周期；共享资源不保存实例状态。
5. 实际制作顺序与内容规模见 [阶段计划](../Demand/Stage/README.md)，不把交付排期堆入架构。
