# 旧驿道洞窟内容与局部照明参数

日期：2026-10-14。状态：已实现旧驿道四区域洞窟切片。

通用机制见 [物品与局部照明架构](../../Architecture/11-物品与局部照明架构.md)。下表记录本内容所用的实现入口，不作为新增地图时必须复制的系统结构。

## 内容实现入口

| 类型 | 职责 |
| --- | --- |
| AdventureItemDefinition / Items/torch.tres | 物品稳定ID、显示名、描述及图标，只读资源，不绑定技能槽 |
| AdventureProgress.Items | 可存档的拥有数量；当前只支持火把，不是完整装备/堆叠系统 |
| AdventureProgress.LitCaveCandles | 已点燃壁烛的稳定ID集合，保存长期地图状态 |
| AdventureSession.TorchInUse | 当前会话的主动使用状态，不序列化；重新启动默认收起 |
| AdventureBackpack | 通过通用CityDialogue显示物品与使用/收起按钮，城市和洞窟共用 |
| CaveLayout | 四岩室、走廊及削角格、出生点、交互点与蜡烛ID；地面、碰撞、遮光共享布局 |
| CaveMap | TileMap地面、岩壁、石路、木构、逐格世界碰撞和遮光多边形 |
| OldRoadCave | 装配角色、交互输入、镜头、环境光、HUD及切图；不复制人物移动实现 |
| CaveFlame / CaveFireSprite | 独立PointLight2D、轻微火焰摆动、火焰自发光；不发放物品或写存档 |

## 交互与持久化

入口位于首城巨石后旧驿道 `(864,475)`，必须先按原流程破石。洞窟出口回到城市 `cave` 入口 `(864,512)`；独立预览洞窟且未破石时回到城门 `(857,294)`，避免进入封闭口袋。沿用AdventureSession显式切图方法，不在本次引入完整WorldGraph或MapDefinition注册表。

领取火把写入 `core:item/torch: 1`，重复领取无收益。主动点击使用后才允许 `LightCaveCandle`；该方法同时检查拥有物品、使用状态、已知壁烛ID及集合去重。场景入口额外校验48像素距离、最近目标、世界射线、模态对话和切图状态，禁止远程或隔墙点火。

蜡烛ID为 `old-road:entrance / west / central / east`。重建地图根据集合创建各自的燃烧表现，局部灯不会通过提高全局亮度模拟。保存仍写 `user://first-city-v1.json`，新增字段有缺省值，版本1旧档向后兼容；读取时补空集合并过滤不识别的ID。当前物品加载仅接受火把，扩展物品时需要同步扩展校验规则。

## 光照与场景生命周期

世界环境由CanvasModulate压暗；洞口仅有小范围微光，随身火把半径108像素，壁烛半径215像素。PointLight2D使用共享径向纹理，岩壁LightOccluder2D采用与碰撞一致的网格边界，光线不会贯穿岩室。微弱环境亮度用于保留近黑的通路轮廓，不覆盖到HUD所在CanvasLayer。

2026-10-24 人物拆件改用共用受光 `CharacterArtwork.gdshader`，洞窟人物接受已有环境暗度与局部灯光，不叠加室外昼夜乘色。完成消息复用 `MessageToast`，位于时钟日期下方；壁烛数量与火把状态条移至底栏上方，避免覆盖消息。

火焰本体使用独立Unshaded表现，避免自身依附岩壁把火焰顶端压黑；灯座和手柄仍参与场景照明。火把与壁烛采用不同能量，降低重叠区域过曝。洞内仅最近可操作目标在上方显示实际按键和动词，不常驻显示名字或底部操作行；提示避开火焰并使用不受局部照明影响的材质。

所有灯光、角色和碰撞节点随场景销毁。跨图只保留生命比例、持久进度与会话使用状态；进入演武收起火把。无新增Autoload、Buff或角色共享资源变更。

## 验证入口

`--cave` 可直接预览；`--cave-test` 进入新内存会话，不碰玩家存档。测试实际操作行囊按钮、交互输入、物理移动、跨场景返回、磁盘存读与旧档迁移，并在有渲染器时截取像素验证近亮远暗。测试文件和实机截图位于 `Build/cave`；首城59项回归日志 `Build/cave/city-regression.log`。
