## 外景分层

| 文件 | 职责 |
| --- | --- |
| `SnowMountainLayout` | 外景范围、原画矩形、山脚入口和上下路岸坐标。 |
| `CityMap.Exterior` | 根据路岸构建路外封闭多边形和山脚终止碰撞。 |
| `SnowMountainExterior` | 独立雪山 Sprite、生成草地地面、生成岩脊路肩。 |
| `ColdMeadow.gdshader` | 活草向稀草、冻土、斑驳雪地连续过渡，路外略压暗。 |
| `FirstCity` | 添加山脚查看点；靠近东门逐步放开镜头边界，靠近雪山拉远并向北观察。 |
| `LocalMinimap` | 同一份路带多边形与入口标记；本地总览使用扩展地图范围。 |

收尾调整：小地图与本地导览使用雪山透明原画呈现实际轮廓，不再把山体画成矩形；山脚终止碰撞不绘制成穿越雪山的长直线。山脚镜头缩放 0.44，保留完整山顶。

城内 60×40 TileMap、五屋、五名 NPC 和旧驿道保持原有布局。东侧城墙只在 y=242–320 开门，演武场继续通过东门交互进入；直接沿路行走则到雪山。地图外景范围 x=932–2304，y=-704–640；背景地面留额外余量，盖在城内 TileMap 下方。

雪山是单张透明地标原画，但草路有独立真实地面与物理边界，并非把整张关卡做成可任意穿行的背景图。人物和坐骑均只能走路带；山脚 `(1650,0)` 可查看，尽头 y=-12 阻挡进入，其他山体与外景均不可进入。当前没有雪山室内场景、传送或新任务，不改存档结构。
