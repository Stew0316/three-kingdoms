# War3 式协调动作的制作标准（历史问题）

原始日期：2026-10-02；整理：2026-10-17。

## 问题摘要

用户当时询问动作应细化到什么程度，并以 Warcraft III 的行走、俯视观察与即时对打作为协调性参考。

按 2026-10-17 的明确要求，本记录已删除原先限制人物精细度、关节精度、脚部模拟、布料模拟及慢放质量的建议和上限表。原始完整问答可从 Git 历史追溯，不能再作为后续制作标准。

## 仍有价值的工作方法

- 先确定实际游戏观察角度与显示尺度，再检查待机、移动、持械、攻击、受击、闪避和倒地。
- 人、动物与物件的运动必须有现实依据；自然程度从重心、支撑、惯性、关节与接触关系判断。
- 正常速度观察整体观感，慢放与逐帧定位脚滑、穿插、跳变和接缝；需要精修的部分继续精修。
- 二维骨架调节不能补出缺失的背面素材；方向覆盖与实际素材能力分别记录，不把镜像视为完整八向资产。
- 动作与玩法时序协同，不能通过改伤害窗口掩盖姿态问题。

本次历史问答没有改变二维运行架构。现行标准以 [正式指南](../../Source/StyleGuide/城池与地形风格指南.md) 和 [2026-10-17 需求](2026.10.17-项目结构整理与三国自然风格规范.md) 为准。
