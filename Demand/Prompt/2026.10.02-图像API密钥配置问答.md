# 图像 API 密钥配置问答

日期：2026-10-02。

用户原话：

> 如何配置 `OPENAI_API_KEY`，我需要去网页版开吗

答复要点：在 OpenAI 开发者平台网页创建 API 密钥，配置该平台的计费，再将密钥保存为 Windows 当前用户的 `OPENAI_API_KEY` 环境变量；重新启动使用该变量的终端和应用。可通过布尔值检查变量是否存在，不输出密钥。

密钥仅供本机素材生成工具调用，不写进 Godot 脚本、游戏资源、Git 仓库或聊天记录。配置说明不代表已替用户创建密钥、充值、修改环境变量或发起付费生图。配置密钥也不能保证消除此前的网络发送错误，需要之后实际验证 API 连接。

官方参考：

- https://developers.openai.com/api/docs/quickstart
- https://developers.openai.com/api/docs/guides/production-best-practices
