## 结果

后续问答：

> 现在HD2D的场景是否用了这几个拆解的部件来完成的

已检查当前项目引用：默认入口为 HD2DArena，吕布/魏延的 Presentation 分别指向已设置 PartsAtlas 的表现配置。运行时 CharacterRig 按 AtlasRegions 生成 16 个独立 Sprite2D 部件并挂在 Bone2D 上，再由 Hd2DStage 的透明 SubViewport 渲染到 Sprite3D，显示在三维演武场中。部件用于角色，不用于搭建三维地台/墙柱；光环和粒子独立生成。旧整图只在 PartsAtlas 缺失时回退，编辑器静态 Visual 仍可能显示旧图，实际应以 F5 运行画面为准。历史 Windows 独立包尚未重新导出。

使用内置图像生成工具，未使用 API key 或 CLI 计费回退。本轮吕布首个请求仍网络失败，魏延成功，随后吕布补试成功。两张图实际输出均为 **1254×1254、32 位 RGBA PNG**，不是提示词请求的 2048×2048；保留生成原始图像和透明通道，未覆盖旧角色原型。

- 吕布：`Source/People/LvBu/lubu-parts-v2.png`。
- 魏延：`Source/People/WeiYan/weiyan-parts-v2.png`。
- 生成默认目录中的原文件保留，项目通过本地副本引用。

两份 `*-presentation.tres` 已设置 PartsAtlas，默认演武场启用新的 16 关节拆件骨架。完整头、胸、腰、上下臂、手、大小腿、披风、武器和冠饰参与动画；旧图仍可通过清空 PartsAtlas 回退。

## 接入校正

生成图片并不严格遵守等分网格：魏延武器顶部越格，吕布上臂包含部分前臂；头和胸的构图也有额外覆盖。新增可编辑 `AtlasRegions`（图集顺序的 16 个 Rect2）以显式选择运行时 UV 区域；保持 PNG 原文件不变。魏延大腿采样在刀刃前结束，武器使用单独纵向区域；吕布上臂采样只保留上半段。冠饰 `CrestRect` 分别适配上扬雉翎和下垂盔缨。持械静止角已调整，让刃端朝向前上方。

这是新素材的可玩骨架原型，仍可继续精调接缝、手部握点和动作曲线；没有新增背面或完整四方向素材，不将镜像压缩旋转称为完整转身动画。

## 魏延最终成功提示词

用途：三国动作游戏的二维骨骼动画生产素材。生成魏延独立身体部件图集，2048×2048 PNG，真实透明alpha背景。写实彩绘风格，森林绿布料、黑铁层叠甲、旧铜配件、绿色披风、实用铁盔、短胡须威严成年中国男性，三分之四面朝右。严格4行4列均匀的隐形网格，每格仅一个独立部件，部件居中且保留透明间距，不重叠不越格，不画完整人物、文字、边框、阴影或棋盘格。第一行从左到右：戴铁盔的头和短胡须；无头无臂胸甲躯干；腰甲短裙；绿披风。第二行：远侧上臂；远侧前臂；近侧上臂；近侧前臂。第三行：远侧大腿；远侧带靴小腿；近侧大腿；近侧带靴小腿。第四行：远侧握拳手甲；近侧握拳手甲；完整竖直单刃长柄大刀，刀刃向上，整件在格内；底部固定的绿色盔缨。四肢竖直向下，上下关节完整补画圆形覆盖区，便于独立大幅旋转，不带邻接肢体。统一光照，精细材质，清晰轮廓，正常成年人体比例。
