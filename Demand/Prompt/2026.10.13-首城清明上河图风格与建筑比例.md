# 首城清明上河图风格与建筑比例

日期：2026-10-13。补充更新：2026-10-14。

## 用户原话

> 现在有个问题，我希望是类似宝可梦的那种城池建筑大小，然后风格我希望是三国风格的，那种国内古建筑的感觉，可以参考一部分黑神话悟空的那种建筑风格，或者是清明上河图的那种风格，不用像黑神话那么细致，帮我写入到AGENTS.md里，我希望说建筑风格以及地形，都是清明上河图的那种风格，然后建筑比例参考宝可梦的火红叶绿的那种感觉，优化一下我的第一个城池

后续补充原话：

> 屋顶也可以搞一点不一样的，然后也可以挂灯笼，灯笼也可以不一样，然后大门或者其他都可以做不一样，尽量不一样的地方多一点，这些也都写入到风格指南里，写一个风格指南吧，然后在AGENTS.md里提示ai每次都去读一下风格指南。

据此建立正式指南`Source/StyleGuide/城池与地形风格指南.md`，并在`AGENTS.md`顶部要求AI每次开始任务先阅读。指南将五屋差异落实到屋顶形制/材料/新旧、檐口、层次、灯笼形状/颜色/数量/挂点、门扇/门帘/门楼、窗棂、墙体、台阶、招幌与生活陈设；通过用途选择组合，保持统一视角、比例、光照和入口清晰。具体五屋搭配以指南表格为准。

继续迭代时的补充原话：

> 继续执行，房顶感觉还是不够特异化，需要有屋檐啥的，然后需要挂灯笼挂招牌啥的，比如酒馆挂一个酒的招牌，铁匠铺挂一个铸造锤的，然军营放了一个刀剑相交的大门

据此强化檐口与附棚结构，将三种具体门面标识纳入指南：驿站侧挂“酒”字布幌、铁匠侧挂铸造锤轮廓标、军营厚木门框上设交叉刀剑门饰。首城驿站表现为兼有酒肆气氛的落脚处，保留驿站原服务，不新增第六栋建筑或售酒系统。

## 与既有RPG设计的关系

`Demand/Design/RPG设计.md`已有连续城镇地图、锻炼、驿站、马厩与骑乘设想；地形章节明确提及《清明上河图》、拱桥、水车、简单码头、小船、房屋、小摊和树，且希望地形线路避免过于方正。该设想作为本轮方向依据，不意味着首城必须一次加入全部景物或新系统。

这轮仍以现有槐安城的微型可玩切片为对象：三条街、五栋建筑、五名NPC，以及任务、军营锻炼、铁匠、驿站、两匹马、演武场入口、崩击巨石与隐藏小路。美术迭代不扩大任务和场景数量。

## 本轮确定的风格

最终优先级以用户后半句为准：**建筑与地形采用《清明上河图》的古城市井气质，建筑比例和地图可读性参考《宝可梦 火红／叶绿》。**

| 项目 | 采用的方向 |
| --- | --- |
| 建筑 | 灰青瓦顶、浅土色墙、深木色梁柱、简练檐口、木门、布幌与小体量门前器物 |
| 地面与自然 | 暖土道路、旧石板、低饱和草地与树冠、自然变化的地面边缘；避免高对比碎纹干扰角色 |
| 比例 | 一栋普通房屋由数个人物宽度构成，适度压缩屋身；屋顶和正面门窗都能看清，角色、门口和街巷关系明确 |
| 视角 | 现有二维俯视世界与TileMap；使用屋顶加正面立面的游戏化表达，不改成等距场景或3D |
| 功能辨识 | 铁匠以炉火、砧台和锤形标，驿站以曲檐、椭圆灯和酒字幌，军营以陡高脊、方灯、交叉刀剑门饰和军旗，马厩以单坡茅木棚与双敞栏区分；横匾是补充提示 |
| 气氛 | 有生活感、能游历的三国小城；暖土、灰青、木褐为主，朱红仅作少量强调 |

黑神话悟空只作为传统木构、瓦顶和屋檐体积关系的辅助印象，不是本轮的主风格；不追求写实级纹样、雕刻密度或巨型殿宇。游戏仍是三国题材；借鉴《清明上河图》的画面语言，不承诺宋代建筑形制的历史复原，也不照搬其具体布局。

火红／叶绿参考的是“小屋相对人物的尺度、道路清楚、功能入口易找”的游戏表达，不直接使用宝可梦素材，也不要求把已有武将换成宝可梦式人物。图集纹理不得参与任务和存档逻辑。

## 本轮实现约束

- 保留五个设施位置和已有可达关系；若显示轮廓调整，同步核对墙体、遮挡、门前交互距离和马厩开口。
- 建筑图片和地面表现负责观感；道路与碰撞仍由地图和建筑的实际参数决定，不能靠一张整体背景图假装可走地图。
- 独立建筑美术放在 `Source/City/HuaiAn`，保留生成原图；接入图允许裁切与透明处理，不能覆盖原武将资源。
- `CityBuilding`从`CityMap`拆分为独立表现文件，建筑贴图替换不触及任务阶段、成长收益和存档格式。
- NPC和马匹已有表现可继续复用；本轮不新增建筑室内、骑战、跨城传送或背包系统。

## 本轮资源与接入

本轮指定接入`Source/City/HuaiAn/huai-an-buildings-qingming-v2.png`，保留v1前版资源。v2为1536×1024透明RGBA图集，采用三列两行，依次是驿站、军营、铁匠铺、民居、马厩、国槐。`Scripts/Presentation/CityArtAtlas.cs`先按各物体自定义窗口隔离相邻内容，再按透明边界获得各自区域；v2部分檐角越过平均分格线，不能直接六等分取样。`CityBuilding.cs`负责建筑显示及引擎绘制的酒幌、锤形标与交叉刀剑门饰。原始PNG保留透明背景，字牌由引擎清晰排字。

v2五屋搭配：驿站曲檐短歇山与双暖白椭圆灯；军营陡高脊直檐与方灯；铁匠不对称灰瓦主屋、低木板附棚与铁框灯；民居旧瓦、茅草侧棚和单小圆红灯；马厩单坡茅木棚、双敞栏和竹编长灯。每栋用屋顶、入口和附属空间形成差异，饰物数量以正常游戏视图能辨认、门前可通行为限。

建筑采用普通房屋墙基约128—144像素宽、开敞马厩约166像素宽的紧凑尺度，屋檐显示两侧合计外伸18像素，地图总尺寸继续沿用现有切片。马厩展示马脚点下移到528、显示缩放0.8，交互点随马匹移动，保持棚檐下的两马可见；骑乘表现和190/250速度保持原设定。镜头采用0.85缩放、向北95像素的观察偏移，避免入城时屋顶被顶栏遮住。

完整生成提示词、原始输出与裁剪接入过程记录在`Demand/美术/2026.10.13-槐安城古建筑图集生成记录.md`。本需求文档只记录风格决策与玩法边界。
