# 项目结构整理与三国自然风格规范

日期：2026-10-17。

## 用户原始需求

> 现在整体项目有点乱了，帮我整理一下，然后文档那些也抽象一下，AGENTS里的东西不要太多，AGENTS.md里的内容，应该只是文件第一级结构，然后只有第一级结构更新，才更新md，然后写明这一级结构是干嘛的。然后代码也梳理一下，按静态定义的都归类，然后骨骼动画的代码也归类，一些配置项也归类，就是提取一下公共部分。
> 然后项目里有提到不要太细致的删掉，有些就是要细致才好看，帮我在AGETNS.md里写明，所有的动作，一定要自然，要和现实世界里的能对应上的人或者物观感一样，包括所有的建筑。然后风格就是按三国时期的，包括色调、建筑风格、人物衣物

后续补充：“继续”。`AGETNS.md` 按项目现有文件 `AGENTS.md` 处理。

## 决定与实现

- AGENTS 收敛为长期协作规则与一级目录职责。日常只有一级目录新增、删除、改名或职责变化才更新；参数、资源版本与验收进入专题文档。
- 三国时期作为色调、建筑、衣物及器物的整体依据。动作以现实对象的自然结构和运动观感为目标，建筑同样要求可信比例、材料、支撑和连接。
- 删除现行指南和模板中统一限制细致程度的要求。允许并重视需要精修的部位，同时检查可读性、接触、遮挡和碰撞；旧问答与生成记录中的限制性文字同步删减并标明摘录，原始版本可从 Git 历史追溯。
- 静态定义、可编辑配置、运行时状态分开；武将资源按人物和动画归组。骨架按绑定、素材、采样、步态、求解、骑乘拆分，提取共用骨链和插值算法。
- 地图按城镇、洞窟、状态、公共能力组织，提取交互查询、矩形墙体/遮光和 UI 样式；选将状态从目录定义移出。
- 根 README 提供阅读入口，Architecture 描述边界，Source 索引描述实际资产，Demand 保存过程与验收；具体组织见 [目录职责](../../Architecture/12-目录职责与公共代码组织.md)。

## 范围和原有工作

整理保留已有玩法数值、技能 ID、存档版本和二维主路线，未重绘全部人物或建筑。新风格规范是制作与验收标准，不意味着当前全部美术已达标。

开始整理时工作区已有上一轮马匹三拍跑步、骑乘和测试改动，以及两张未接入的马匹拆件候选。本轮保留这些内容并运行回归；原图不改写，不把未接入候选当成当前坐骑素材。`BaseSource`、`addons` 子模块不修改。
