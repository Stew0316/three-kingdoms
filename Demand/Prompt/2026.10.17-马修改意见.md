# 2026-10-17 马动作修改意见

## 说明

本文为网页摘录整理的第三方修改意见，保留原始判断与建议内容，供后续马匹动作返工与验收对照使用。意见中的具体数值（灰度、倍数、比例、帧号）来自对方对缩小图集与 GIF 的目测量取，属于估计值，实际接入时按本项目骨骼的缩放与重叠关系复核。

## 修改建议 1：腿部造型与遮挡关系

整体判断：节奏和大姿态其实没问题。起步、腾空、落地、伸展的顺序是对的，躯干上下起伏也有。怪的地方集中在腿本身的造型和遮挡关系上。

### 问题

1. **腿的上半段没有"腿"的感觉**

   大腿和前臂的肌肉是画在躯干上的，只有下半截是一根粗细几乎不变的细杆。腿一转动，肩和髋的位置就像一个鼓包被拉扯出一条棍子。第 12、14 帧最明显：后腿像是从肚子下面冒出来的，而不是从臀部长出来的。

2. **近侧腿和远侧腿混在一起**

   第 0、18、20、22 帧收腿阶段，四条腿都挤在肚子下方，颜色亮度一样，分不清哪条在前哪条在后，所以看着像一团乱线。远侧的两条腿没有压暗，这是最容易修的一点。

3. **腿的比例和关节**
   - 躯干肌肉很厚，下腿却又细又直，蹄子偏小，对比之下腿显得"不是这匹马的"。
   - 第 8、10、12 帧完全伸展时，腿看上去比收起来时更长，像被拉伸过。如果动画里用了缩放，这里要去掉，腿段长度应当固定，只靠旋转。
   - 马后腿的关节是"之"字形：膝（stifle）向前，飞节向后，球节再向前。腿伸直或收拢时，这个折线都应该看得出来，现在只能看到一条斜线。

4. **影子是静止的**

   地上的椭圆影子一直不动，而马在上下起伏，腾空时蹄子离地好几十像素。让影子随高度缩小变淡，是低成本又很有效的修饰。

### 修改顺序（由易到难）

1. 远侧腿的 `Modulate` 调成约 0.7 的灰度，并且放在躯干后面一层绘制。
2. 影子随马身高度缩放和淡化。
3. 检查所有腿段有没有缩放，有就去掉，改成只旋转。
4. 收腿阶段限制折叠角度，避免四条腿重叠到一起。可以让近侧和远侧错开约一个相位。
5. 重新切一下腿：把大腿和前臂做成独立部件（连同肌肉），躯干上对应位置补一块"髋窝"和"肩窝"底图，转动时不会露出空洞。
6. 蹄子放大约 1.2 到 1.4 倍，下腿稍微加粗。

## 修改建议 2：腿段比例与躯干风格

### 问题

1. **每条腿的四段长度几乎一样（最明显）**

   我按图集把每条腿的四块量出来了，数字是像素高度，分类是我的理解：

   | 腿     | 上臂／大腿 | 前臂／小腿 | 炮骨 | 系部＋蹄 |
   | ------ | ---------- | ---------- | ---- | -------- |
   | 前腿 A | 233        | 231        | 234  | 168      |
   | 前腿 B | 204        | 217        | 212  | 154      |
   | 后腿 A | 233        | 224        | 220  | 150      |
   | 后腿 B | 215        | 211        | 213  | 148      |

   真马的前臂最长，炮骨约为前臂的 0.6 倍，系部加蹄约 0.35 倍，也就是约 1 : 0.6 : 0.35。这里是约 1 : 1 : 0.7，炮骨和蹄都偏长。这样的腿在动画里就像一根等分的竹竿，弯折时没有真马那种"短而硬的下腿"的感觉，看起来怪就怪在这里。

2. **躯干太长太细**

   放大的 GIF 里，躯干长度（臀到胸）约为身体深度（背到腹）的 2.7 倍，真马大约是 2.1 到 2.3 倍。图集里的躯干筒本身是 352×185，两端又接了胸块和臀块，所以整体偏"腊肠"。

3. **肌肉块和躯干风格不统一**

   胸块、臀块、大腿块的肌肉纹理很重，像解剖图；躯干筒和颈部却比较光滑。拼起来有一种"贴上去"的拼装感，头相对颈肩也显得小。

### 调整建议（先在静止站立姿势下调，再看动画）

1. 把四条腿的炮骨在 Y 方向缩到约 0.6 倍，系部加蹄缩到约 0.5 倍。关节处保持重叠，白袜的纹理会略微压扁，但不明显。
2. 躯干筒横向缩 15% 到 20%，或增加它与胸块、臀块的重叠，直到身体长度与深度之比约为 2.2。
3. 降低胸块、臀块、大腿块的对比度和纹理强度，叠一层统一的色调，让它们和躯干接近。
4. 调完后对着 Muybridge 的照片再核对一遍站立姿势。

> 这些数字是我从缩小的图片里量的，部件在骨骼里还有各自的缩放和重叠，所以只是估计。

## 常见原因对照

| 现象                           | 常见原因                                                 | 修法                                                         |
| ------------------------------ | -------------------------------------------------------- | ------------------------------------------------------------ |
| 腿像钟摆一样来回摆，很机械     | 用匀速正弦波驱动，真马的腿是"抬起收回快、着地蹬地慢"     | 关键帧里让收腿阶段更短、更快，着地阶段更长，不要用对称的曲线 |
| 马在地上"滑"，像滑冰           | 蹄子着地时在往后移动的速度，和背景滚动速度对不上         | 着地腿的后蹬速度要和地面移动速度匹配，或者背景速度按步幅算   |
| 膝盖弯的方向像人               | 马的前腿膝盖（腕关节）收腿时是向后折的，而且下腿折得很紧 | 反转下腿的旋转方向，收腿时下腿接近折叠到大腿下               |
| 四条腿同步，或者前后腿完全对称 | 相位没错开                                               | 奔跑时四腿是依次落地的，不是两两同步                         |
| 腿动了，身体像一块硬板         | 躯干、脖子、头没有联动                                   | 加躯干俯仰、脖子随步频点头、头部延迟跟随                     |
| 腿转动时关节处裂开或错位       | 旋转中心没放在关节上，或者部件在关节处没重叠             | 检查每个部件的支点，关节处让上下部件的图有重叠               |
| 马和骑手像两个东西             | 骑手随马身一起刚性移动                                   | 骑手上下起伏比马身晚约半拍，上半身稍微反向摆                 |
| 整体感觉轻飘飘                 | 没有腾空相和蓄力相                                       | 奔跑周期里要有四蹄离地和四腿收拢在身下的两个姿势             |
