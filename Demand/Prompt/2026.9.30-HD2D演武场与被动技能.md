# HD2D 演武场、拆件骨骼与被动技能

日期：2026-09-30。

后续更新：2026-10-02 已通过内置生图生成两张拆件图并接入默认 16 关节动画，见 [生成与接入记录](2026.10.02-拆件图生成与接入.md)。下文“未完成的素材”为本文件记录时的历史状态。

## 用户要求

> 帮我建一个HD2D的演武场，还是用的吕布和魏延，但是我希望有更细的骨骼动画，而不只是轻微动作骨骼的图片你帮我继续生成一下，让细微的动作可以更顺畅一点。我希望能做出更大幅度的动作，然后脚底下有光环，光环帮我做一下，光环旁边带一点粒子效果，然后吕布和魏延的粒子效果不一样。然后移动的时候，吕布移动的时候加一点拖影，有点像DNF蓝拳的那种拖影
> 给吕布还有魏延加一下技能，吕布加两个被动，一个被动是被攻击的时候，反弹20点伤害，一个是攻击的时候有概率暴击，概率32%，暴击伤害是180%。
> 魏延的一个被动是被攻击，概率在周围转一下，像是dota2斧王的反击螺旋一样，伤害为30点伤害，概率是60%。还有一个被动是概率暴击，概率15%，暴击伤害是240%。注意抽象参数

补充：

> 吕布魏延的人物形象，可以不用原来的，可以参考原来的。不是一定要和原来的一样

## 已实现

- 默认入口 `Scene/HD2DArena.tscn`：真实三维石台、墙柱、旗帜、台阶、固定正交斜俯视镜头、阴影、灯光、雾和辉光。二维角色使用透明独立 SubViewport + Sprite3D。
- 保留唯一二维战斗物理，按 `(x-320, y-210) × 0.02` 映射到三维 XZ。所有范围提示用同一映射。
- 吕布暖金环和上升火星，魏延青绿环和绕行光屑。配置颜色、数量、半径、轨迹类型。
- 吕布移动时每 0.075 秒采样当前姿态，蓝色残影留在原世界位置并于 0.32 秒内渐隐；暂停冻结，结算清除。两个角色只需要最多约五张并存快照；大量小兵场景应改成渲染纹理池，当前未做压力优化。
- `PassiveConfig` 抽象固定反伤、概率暴击、周身反击。配置在 `Resources/Config/Combat/lubu.tres` 与 `weiyan.tres`，可在 Inspector 修改。
- 暴击倍率是总伤害：1.8 / 2.4，最终四舍五入成整数。每次主动攻击命中独立掷骰，普攻、突进、横扫均参与。
- 反伤固定 20，受有效主动攻击即触发，包括致命攻击。魏延反击概率 0.6、伤害 30、原型半径 68、表现时长 0.48 秒；致命受击不反击。
- 反伤/反击不再触发被动、暴击、硬直或打击停顿，队列最多处理 32 请求。整条链结束再结算；同时死亡按玩家失败处理。
- HUD 从同一配置生成被动数值说明；伤害飘字区分暴击、反伤、反击。

## 尚未完成的素材

内置图像生成工具对吕布一次、魏延一次、吕布重试一次，均返回网络发送错误；没有产出任何新 PNG，也没有替换旧素材。没有擅自切换需要 API key 和计费的 CLI 路线。
