# 吕布爆气动作与魏延全身气焰修正

日期：2026-10-27。状态：已接入并通过实机回归。

## 用户要求

- 吕布爆气时不要额外挥舞武器，直接爆气即可。
- 魏延的爆气应和吕布一样从全身散发，不能只从脚底冒出。

## 原因与修改

两人的强化技能原先使用 `Motion = 2`，对应横扫，因而施放强化也会进入挥击曲线。改为独立的 `CombatMotion.Empower`，由当前姿态平滑收稳到自身持械站姿；不播放普攻、横扫、空间攻击片段或攻击刀光。旧拆件与历史动画回退同样遵守这一语义，不按人物姓名或输入槽位特判。

魏延原先 `EmpowerHumanAura = false`，只启用了武器辉光和位于角色原点的上升粒子。现开启与吕布相同的前后双层全身气焰，保留白色主色、长刀白光和移动蓝色残影；全身气焰启用时原点粒子不再发射。气焰尺寸继续根据实际头部与脚点定位，覆盖双腿、腰胸、双肩至头顶以上。

两项技能的施放时间、增伤倍率、强化时长、冷却及稳定 ID 不变。本次没有生成或替换图片，也未改变关羽的动作与赤红气焰。

通用表现合同见 [角色组合架构](../../Architecture/09-武将模型动作UI与技能组合.md#2-输入槽动作语义与技能身份)。原气焰实现历史见 [铁铜量表与全身爆气](../美术/2026.10.23-铁铜量表与全身爆气.md)，其中魏延仅用武器辉光的旧记录由本次要求更新。
