# S3：吕布的第一次技能收集之旅

前置：S2 战斗内核可用。预算 50–90 有效小时。目标：玩家为了获得并尝试新技能，愿意离开安全点、完成挑战，再回到已走过的地方。

2026-10-02 路线更新：S3 地图主体采用《宝可梦 火红／叶绿》式二维俯视 TileMap，战斗保持即时制。HD2D 演武场作为技术样板保留，不作为本阶段地图模板。

## 最小冒险闭环

```text
小村训练场 / 驿站
    ↓ 接到“旧道试锋”任务
野外旧道：基础兵 → 路线分支 → 精英挑战
    ↓ 获得一个明确的新技能
短洞窟：试用新技能，开启捷径或取得额外奖励
    ↓
回驿站：恢复 → 查看技能图鉴 → 调整搭配 → 保存
```

只需 1 个安全点、1 段野外、1 个小洞窟和 1 次主要挑战。这是占位可玩的功能版；S4 沿用它打磨为 20–30 分钟正式切片。

## 吕布成长和技能规则

| 项目 | 规则提案 |
| --- | --- |
| 技能收集 | 一次性挑战、师承任务、探索秘卷给出确定奖励；不靠重复刷低概率掉落 |
| 已学与装备 | 学到即永久记录；最多 3 个主动槽 + 1 个被动槽；普攻/闪避另列 |
| 装备时机 | 仅安全点且脱战时调整；不在 Boss 战中打开背包临时换克制技能 |
| 技能 CD | 按技能实例保存；拆卸重装不能刷新，读取存档也不能带来战斗内刷 CD |
| 技能强化 | 每个技能先只做 1 个强化节点，例如宽度或击退增强；不为每个技能做树 |
| 基础成长 | S3 只演示少量等级及 HP/伤害提升，先封顶；Boss 通关无需反复练级 |
| 装备 | 保留固定戟、一个饰物、少量回复品；新武器先改参数与外观，不增加完整动作体系 |
| 收集展示 | 技能图鉴显示用途、获得线索、伤害/冷却、控制或位移标签；未获得条目只给线索 |

挑战者可示范招式，胜利后将其改编为适合吕布的玩家版。Boss 的全屏范围、连续硬控和无敌不原样继承。收集是一种新的玩法选择，而不是只把伤害数字提高。

## 地图如何借鉴合金弹头

使用二维俯视视角，将“连续推进中出现新威胁和场景事件”的想法转为相连区块：远处可见地标 → 接敌 → 一次地形变化或伏击 → 短喘息 → 精英。局部战斗允许绕行；不把每一屏都锁门清怪。

- 主路大致清楚，留一条能绕到弓兵侧后的短支路；支路在同一地图内汇合。
- 高低差用台阶 Tile、前景遮挡、入口切层和不可跨越边缘表达；不做跳跃物理、真实坡面或 3D 地形。
- 宽场测试横扫，狭道测试突进收距，柱子/掩体测试视线与走位；一次只引入一种新组合。
- 强制战斗只放在任务挑战区。触发前说明边界，战后解锁；失败可迅速从入口重试。
- 能力门只控制可选宝箱、近路或额外挑战；主线必需能力应在门前获得，且不会因未装备而永久卡关。

详细节拍、参考来源与区别见 [关卡与成长借鉴](参考-关卡与成长借鉴.md)。

## 魔女之泉式锻炼的轻量落地

安全点设“演武场”，提供技能试用与有限成长，作为游历中可返回的地方。S3 实现 1 课，S5 最多 3 课：闪避反击、方向突破、技能组合。

| 规则 | 设计 |
| --- | --- |
| 每课时长 | 一次成功尝试目标 30–60 秒，无长倒计时等待 |
| 收益机会 | 首次解锁有 1 次；成功训练消耗，连续 100 分钟未锻炼后恢复 1 次；所有课程共用，不累积多次 |
| 再次练习 | 有额度且未达章节上限时可以再次成长；无额度仅练动作，且复练会重新计算休息时间 |
| 累计上限 | 本篇暂定最多 3 次成长，每次初始基准 HP +2%、总计不超过 +6%，不复利 |
| 奖励持久化 | 保存收益会话 ID、章节次数、额度和最近训练 UTC 时间；同一会话不重复领奖 |
| 节奏 | 现实时间含暂停/离线；NPC 提示出去游历，界面显示倒计时与上限，不按零点刷新 |
| 通关公平 | 主线必需招式不锁在高难训练成绩后；训练优势有限，可提供辅助提示 |

按用户最新要求，100 分钟连续不锻炼才恢复收益；失败不扣尚有的额度，但实际练习结束会记录时间。详细规则、时间示例和边界验收以 [锻炼收益与实际时间](设计-锻炼收益与实际时间.md) 为准，不把这些数值声称为已核实的参考游戏规则。

南华以手札或传闻引出训练。左慈在第一次主要挑战后的剧情节点解锁传送，本阶段先实现两个已到访安全点间往返；将已到访、已激活和剧情解锁分别保存。传送免费且不占战斗技能槽，战斗/剧情封闭区禁用；重要奖励之后放安全归驿点，避免逆向再跑全图。各城分身扩充和基础坐骑骑行放 S5，详见 [坐骑与三仙](设计-坐骑与三仙传送.md)。

## 系统与数据

任务只做一个简单状态流程：未接取 → 进行中 → 条件满足 → 已领奖。战斗发出唯一击败事件，任务系统更新计数；领奖和技能解锁幂等，读档后不重发奖励。

存档记录 `schemaVersion`、游戏版本、存档槽 ID、内容包版本、当前地图/安全点、等级/装备、已学技能/强化/槽位、已完成任务/课程、一次性拾取与开门状态。使用稳定 ID，不存节点路径或直接序列化场景树。

只在安全点、挑战完成且战斗效果清理后保存，不做战斗中任意快照。流程为写临时文件 → 校验 → 保留上一份备份 → 替换；崩溃恢复只读完整版本。设置与进度分开，画质/分辨率保留本机，为 S6 云存档留边界。

失败返回最近安全点，不丢永久已学技能；本次尚未完成的战斗奖励不发放。存档落点必须可行走；未知地图、缺失内容包或非法位置回到安全点，并保留未知内容数据以便恢复。

## 验收与交付

- [ ] 新存档从安全点完成出发、挑战、学技能、试用、回营、装备与保存，全流程没有开发按钮。
- [ ] 关闭程序再进入，技能、强化、任务、课程与开门状态一致；重复领奖无额外收益。
- [ ] 战斗区不能换技能；离场、脱战和保存不会留下持续伤害或幽灵光环。
- [ ] 主路/支路均能到达目标；未选某一强化不锁死主线；重访至少发现一处有意义的新用途。
- [ ] 收益用完后连续 100 分钟未锻炼才恢复；离线计时、无收益复练重置、换课共享额度、章节上限和存读档均正确。
- [ ] 左慈解锁后可在两个安全锚点往返，未到访点不可选，战斗中无法传送，读档后激活状态仍正确。
- [ ] 删除或破坏最新存档副本时，能提示并恢复备份；不自动覆盖唯一正常档。
- [ ] 保留一份旧版本样例存档，验证一次向后迁移；未来版本档不强行降级读取。
- [ ] 简中界面完整，切换伪翻译/长英文样本仍能操作；文案不烧进贴图。

本阶段不做全国地图、招募与编队、无限训练、随机装备、自动生成任务。交付 1 份可从头到尾玩的导出包和一张地图逻辑图。
