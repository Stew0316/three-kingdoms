# S4：20–30 分钟能代表最终品质的切片

前置：S3 闭环可玩。预算 60–100 有效小时。目标：用小段成品同时验证手感、技能收集、关卡节奏、画风与单人制作成本。

## 一次试玩的节奏

| 时间目标 | 体验内容 | 应验证的价值 |
| --- | --- | --- |
| 0–3 分钟 | 吕布在安全点，与老师/驿站互动；一课可选训练 | 迅速进入操作，能理解补给与成长 |
| 3–8 分钟 | 旧道基础敌人、地标与小分支 | 主路清楚，战斗与探索交替 |
| 8–13 分钟 | 盾/弓组合与绕侧路线，小挑战奖励牵引技能，安全点换装 | 地形使技能选择有意义，学到后立刻能搭配 |
| 13–20 分钟 | 试用新技能、打开短近路，进入守将挑战 | “收集能力”改变打法，预警与失败原因清楚 |
| 20–26 分钟 | 击败魏延或守将、结算，左慈解锁两点传送 | 新打法得到验证，回程无需重跑整段路线 |
| 26–30 分钟 | 回驿站，强化/装备、存档，一封短来信或离行钩子 | 一轮游历完整结束，愿意继续 |

这是设计节拍，不用不可跳过对话硬凑时长；熟练玩家更快属正常。训练可跳过且不影响通关。

具体约 25 分钟的遭遇布置见 [参考节拍表](参考-关卡与成长借鉴.md)。切片开始已有突进、横扫和一项师承守势，途中牵引成为第 4 个可选技能，验证“三槽不能全装”的取舍。安全点、旧道、废寨洞口/短洞窟复用三个场景容器；左慈归乡道标与城门驻点沿用这些场地，不新增整座城。

## 成品资产清单

- 吕布：四朝向移动/普攻、受击、死亡，技能尽量复用动作与独立特效；先做好一套核心戟术。
- 人形对手：2 类基础兵 + 1 名主要对手，允许共同动作骨架/规格，保持轮廓区别。
- 地图：安全点、旧道、短洞窟，共用一套地块和建筑语言；一处有记忆点的地标。
- 表现：一套普攻刀光、一次冲击命中、一种脚下光环、一种技能蓄力预警、一种残影；不同时做所有愿望特效。
- UI/音频：技能槽、CD、血条、任务提示、训练结果；命中/受击/脚步/环境和战斗音乐形成基本层次。
- 文本：切片简中正式文案；繁中、日语、英文各选一段 UI/技能/对白做排版样本，不把样本当作完整翻译。
- 便利与生活：左慈分身/道标和短解锁演示；坐骑仅做静态尺度样板，基础骑行到 S5 制作。

规格与生成流程分别以 [美术规范](风格-美术与特效规范.md) 和 [生图模板](风格-生图提示词模板.md) 为准。S0 样板在这里冻结为可复用参考，候选生图经切片修整和动画检查后才进入游戏。

## 粒子、着色器和可读性

刀光表现挥动方向、强弱与节奏；光环说明状态和归属；预警告诉玩家伤害位置与生效时间。装饰只在这三项清楚后追加。

先实现短闪白、轮廓/受击染色、刀光淡出和光环滚动等小效果。粒子用于短碎屑、扬尘和有限余焰；残影数量有上限。不要把“有 Shader”视为优化结果，屏幕采样、叠加层和透明覆盖也可能增加开销。

性能目标是提案，需指定测试机后才有效：

| 测试 | 预算/判据 |
| --- | --- |
| 基准包 | Windows 导出包、固定渲染器、固定 1920×1080 输出和 640×360 世界逻辑视口 |
| 常规战斗 | 吕布 + 最多 8 个敌人，连续技能运行 5 分钟，目标 60 FPS |
| 帧时间 | 目标 p95 ≤ 16.7ms；同时记录 CPU/GPU、最大尖峰与加载停顿，不能只报平均 FPS |
| 压力样例 | 12 个敌人 + 约定最坏效果组合；用于找到超限来源，不等于承诺常态同屏规模 |
| 稳定性 | 往返地图与重开约 20 次后，节点/活动效果数回到基线，内存没有持续单调增长 |
| 低效果档 | 降粒子、残影、装饰光环、屏幕扰动；伤害范围、预警和技能时序保持一致 |

现有工程使用 Forward Plus / Windows D3D12 配置。先测再决定是否采用其他渲染器，不因“2D”直接改动；替换前后须检查粒子、材质、文字、打包结果。S4 留下本机与一台较弱机器的记录；拿不到第二台时明确标未验证。

## 对外试玩与停止条件

邀请至少 3 名未参与开发的人，少做口头教学，记录到首次战斗/习得/通关的时间、死亡点、迷路点、技能使用次数与最想继续尝试的内容。参考目标：至少 2 人能独立完成，且都能解释新技能的用途和 Boss 的一个破绽；小样本只用来发现问题，不当市场预测。

若两轮调整后仍普遍迷路、看不清危险、只用普攻或技能只有数字区别，继续修此切片。不要马上扩至多座城。

## 验收与交付

- [ ] 20–30 分钟首次体验目标得到实测记录，流程有开始、成长和结束。
- [ ] 地形、角色、技能图标、刀光/光环符合同一风格版本；没有临时素材混入成品路径。
- [ ] 训练、关卡组合与技能获得各有一次清晰展示，主角始终为吕布。
- [ ] 至少两种技能搭配有不同打法；新能力能在后续场地立即试用。
- [ ] 低效果档也能识别全部伤害预警，震屏和强闪光可以降低或关闭。
- [ ] 完成性能与试玩记录，并据此冻结 S5 内容上限和重新估时。
- [ ] 导出包、30–60 秒实机展示、风格参考样板、问题清单可供后续复用。

Steam 商店素材可从此阶段积累；用一项小验证检查候选平台封装能否在当前 Godot C# Windows 导出中初始化，尚不接成就与云同步。没有开发账号也不阻塞玩法制作，但需在 S6 前补齐验证。
