# S5：把切片扩成一个完整小篇章

前置：S4 风格、核心乐趣和产能验证通过。预算 120–200 有效小时，需按 S4 实绩重估。目标：完成一个有开头与结尾的中原游历篇章，不以铺满三国大陆作为首发条件。

## 内容冻结

以 [总览](README.md) 的范围上限为准：1 村、2 小城、4 野外块、2 小洞窟；4 类基础人形兵、3 场主要 Boss；8–12 主动技能、最多 3 被动；1 主线、最多 3 短支线。总首次流程约 2–3 小时，以实测为准。

推荐主线结构：离开小村 → 第一城获得新的技能线索 → 旧道与矿洞试炼 → 第二城及人形守将 → 决战收束当前旅程。原文大世界与复杂人物命运留作素材库；首次篇章只用老师、一个伙伴、家书等少量关系建立情感，不并行制作游侠/争霸双主线。

## 批量制作方式

每一个关卡单元都按“灰盒路线 → 接敌与喘息节奏 → 能力/物品奖励 → 失败返回 → 最终美术 → 本地化/存档回归”完成，不能先画完所有城镇再补玩法。

| 内容线 | 处理方式 |
| --- | --- |
| 人形兵种 | 枪兵管距离、盾兵管方向、弓兵管站位、刀兵作基础压力；不先上硬性克制倍率 |
| Boss | 各测试不同能力：方向与走位、牵引与蓄力窗口、已有机制的组合；每个最多新增一个底层机制 |
| 技能收集 | 分布于主要挑战、短支线与探索；每种技能有明确用途，重复奖励改成有限强化资源 |
| 驿站 | 恢复、存档、整理技能；传送仅限已到达安全点，减少无意义重复跑图 |
| 左慈与三仙 | 每城一个复用造型的左慈分身，剧情解锁后连接已激活点；南华以手札引导修行，于吉占用最多 3 支线中的一条，不额外增开长篇 |
| 坐骑 | 1 匹普通马提供非战斗赶路，赤兔候选、总上限 2；家中马厩展示/简单互动，入战下马，不做马战或每日照料 |
| 训练 | 最多 3 课，共享每轮收益额度；连续现实 100 分钟不锻炼恢复，含离线时间；章节累计成长封顶，显示倒计时/上限/复练重置说明 |
| 洞窟 | 火折子一次获得，点亮/机关状态持久化；不加入消耗照明资源的额外经济压力 |
| 地图 | 主路清楚、短支路汇合、至少一处重访新用途；能力门不锁死流程 |
| 剧情表现 | 短对白、来信、地图事件为主，关键演出只做少数可复用段落 |

## 多语言不是最后替换字符串

目标为 `zh_CN` 简中默认、`zh_TW` 繁中、`ja` 日语、`en` 英文。首次启动默认简中，设置中可随时选择并持久保存；不因系统语言覆盖用户选择。

翻译表覆盖 UI、技能描述、任务、对白、交互提示与错误说明；ID 不译，显示名经翻译键读取。带数值的描述使用可重排的占位符，禁止拼接中文片段。Godot 支持翻译资源、运行时语言选择及文本查找；字体覆盖与占位符顺序需要独立验证。[Godot 国际化文档](https://docs.godotengine.org/en/stable/tutorials/i18n/internationalizing_games.html)

技术上沿用引擎翻译机制，选择 CSV 或 PO 中一种作为权威源，不双向维护。此处仅设计，不在本次创建表格。界面需验证中日字形、英文长文本、换行、数字格式、按键提示和切语后缓存文本刷新；文字与场景贴图分离。人物名、术法名、兵种名建立术语表，翻译包含语境、字符空间和截图。

首发计划按四语完整检查。日英至少完成理解与润色审校；简繁转换也需复核用语和断行。若无能力完成校对，应重新决定语言发布范围，不能把未完成语言宣称为完整支持。

## 操作、设置与辅助

- 键鼠与手柄都能进入游戏、战斗、训练、装备技能、对话、设置与退出；焦点不会丢失。
- 输入重绑定，按钮提示随设备变化；不在文案或教程贴图中固定写“按 J”。
- UI 缩放/文字可读性、主音量/音乐/音效、画面模式、效果质量、震屏/闪光开关。
- 无敌帧、瞄准辅助或难度调整若加入，必须保持解释清楚；S1 无无敌闪避仍是基线，新增机制需回归 Boss 窗口。
- 技能图标有文字与形状补充，友敌/危险不要仅凭颜色区分；暂停与重试路径始终可达。
