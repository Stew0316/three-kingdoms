# S6：Steam 接入与发布验收

前置：S5 内容与关键质量问题收敛。开发预算 40–70 有效小时，不含审核等待。目标：从“编辑器能玩”推进到“玩家通过 Steam 安装、运行、存档、更新都正常”。

本文是待执行计划；本次没有注册账号、支付费用、上传包或发布商店页。

## 提前与最后分别做什么

| 阶段 | 提前处理的事 |
| --- | --- |
| S0 | 尽早验证 Windows 导出，明确工具与模板版本 |
| S2 | 内容稳定 ID、成就可订阅的领域事件、平台调用边界 |
| S3 | 版本化本地存档、设置分离、离线平台实现 |
| S4 | 候选 C# Steam 封装的导出初始化小验证；积累实机展示素材 |
| S4–S5 并行 | 开发者资料、AppID、商店文案/截图/宣传视频、真实功能列表与语言支持 |
| S6 | 正式接入成就/云存档/内容可用性，上传测试分支并完成发行验收 |

Steam 商店准备不必等所有内容完成；但预告和页面只能描述实际计划且可交付的内容。不要把多人、全三国大陆或尚未决定的 DLC 写成首发功能。

## 平台边界

采用小型 `IPlatformServices` 门面，让游戏能使用 `OfflinePlatformServices` 或 `SteamPlatformServices`。场景、技能和任务不直接散落 Steam API。只暴露当前需要的能力：初始化状态、成就、用户存档命名空间、内容包可用性；云存档若选 Auto-Cloud，不额外自建云上传接口。

候选封装必须实测 Godot 4.7.1 C#、Windows x64、当前 .NET 目标、原生依赖与独立导出。按实际支持情况选择并锁定版本；此设计不凭名称承诺某插件兼容。

Steam 不可用时基础单机流程仍可运行，不能因为成就服务失败阻止进入游戏；平台错误记录清楚。离线成就以本地事件去重，恢复服务后按平台能力同步。DLC 的“未拥有、未安装、暂时无法判断”分别处理，不能一律删除存档里的内容。

## 成就和云存档

首批成就只做少数有自然目标的条目，例如首次学招、完成三课训练、完成篇章；不要诱导数百次重复刷怪。内部成就 ID 稳定，平台端显示名可本地化；重复提交无副作用。

优先评估 Steam Auto-Cloud：同步已校验的进度文件与必要元数据，画质/分辨率等机器设置留在本地。官方文档区分 Auto-Cloud 配置与 Cloud API，且明确不建议同步机器特有配置。[Steam Cloud](https://partner.steamgames.com/doc/features/cloud)

存档设计需支持 Steam 用户隔离与开发/离线用户命名空间。第一次转为 Steam 用户档时做一次显式迁移并保留源档；不把另一位用户的本机进度静默覆盖过来。断网、双机进度分叉与客户端同步选择后的文件变化都要实测，禁止应用用“时间最新”盲目覆盖备份；备份/恢复策略与具体同步文件范围一起验证。

## 发行窗口与官方流程

资料核验日期为 2026-09-28；真正发行前重新核对后台清单。官方入驻页目前列出首次若干产品存在付费后 **21 天**等待，以及 Coming Soon 公开至少 **2 周**等条件；这些时间可以与开发并行，不能算成最后一天的按钮操作。[Steam 入驻说明](https://partner.steamgames.com/doc/gettingstarted/onboarding)

商店页与游戏构建分别需要完成检查和审核；提交商店页审核在前，通过后按实际流程推进构建检查。准备好之后仍需主动执行发布操作，不是审核通过就自动上线。[Steam 发布流程](https://partner.steamgames.com/doc/store/releasing)

平台等待规则不等于本项目发售日承诺，保留修改和重新提交的余量。价格、收费与公开发行日期由实际发行安排决定，本次阶段设计不替用户做商业定价。

## 验收矩阵

| 情况 | 预期 |
| --- | --- |
| 干净 Windows 机器、无编辑器 | 从 Steam 安装后能启动并通关；资源与 .NET/原生依赖齐全 |
| Steam 正常 / 客户端关闭 / 离线 | 基础游戏和本地档可用，平台失败有可追踪日志 |
| 成就重复与断网补记 | 不重复奖励、不回滚本地进度 |
| 两个 Steam 用户用同一电脑 | 档案隔离，首次迁移保留备份 |
| 两台机器、离线后恢复 | 云同步后读取正确版本，冲突过程不会丢失唯一正常档 |
| 更新旧版本 | S3/S4/发布前样例档能迁移；过新版本档不被旧程序覆盖 |
| 有/无测试扩展包 | 基础流程稳定；不可用的内容有一致提示与恢复路径 |
| 启动参数、窗口、Overlay、手柄 | 焦点、输入、暂停与恢复正常，不发生双重输入 |
| 四语言与正式最坏关卡 | 文本、字体、性能满足 S5/S4 指标；机器规格有实测依据 |

## 交付与发布门槛

- [ ] 对应版本号的 Release 候选包、构建记录与素材清单。
- [ ] 测试分支安装/更新验证通过；能回退构建，并说明旧程序对新档的限制。
- [ ] 商店图文、实际画面、语言和控制器支持声明一致；最低配置来自测试记录。
- [ ] 主线阻塞、崩溃、存档破坏与核心判定错误清零；已知轻微问题有处理安排。
- [ ] 发布前保留关键样例档和包；发布后有可复现的问题收集方式与修复优先级。
- [ ] 商店和构建均通过平台要求的审核；实际公开发布另按届时的用户指令执行。

Steam Deck、Linux/macOS、多人与 PvP 不属于此阶段交付；没有测试就不宣称支持。
