# 坐骑与三仙：让游历有陪伴，重访少跑路

依据：用户 2026-09-28 补充，希望借鉴魔女之泉宠物，将其转为少量三国坐骑，并让左慈在某剧情节点开放各城分身传送。本文件作为阶段设计的一部分；三仙职责是本作的传说化设定，不作为历史考据结论。

## 三仙的功能分工

| 角色 | 在游历中的作用 | 首发最小表现 | 控制成本 |
| --- | --- | --- | --- |
| 南华老仙 | 提供修行理念与练习方法 | 一本传下的练功手札、老师的提及或短暂出场，引出演武场 | 不需要独立大地图和长剧情；课程仍由既有训练点执行 |
| 左慈 | 解释城池间的快速移动，让旧区域重访便利 | 一次关键相遇，各城一个分身，同一传送列表 | 分身复用角色资源/交互组件，以地方对白区别 |
| 于吉 | 连接市井传闻、选择与术法探索 | 一条短支线，奖励一个技能或有限强化 | 不把原设想的通缉、监狱、劫法场、多结局全塞进首发 |

三人可以通过同一修行/方术语汇联系，但不要求做成三个同级导师系统。吕布仍是唯一可操作角色。

## 左慈传送的解锁剧情

暂名“留影问路”：吕布到达第一城并完成首个主要挑战后，帮助左慈找回一枚散落道符。左慈认可其游历志向，赠予“行旅符”，解释城池分身是可联通的道标。

这是主线必经的轻量事件，约一次对白与一次就近互动，不安排先跑三趟城外的任务。解锁时间放在玩家已经理解一段路、即将开始重复往返的时候，而不是通关后才给便利。

各城均有一个可见分身，位置固定在驿站/城门附近。能力未解锁时可见简短伏笔；已经到访并交互过的城在剧情解锁时一并激活，新城必须亲自抵达后与分身交互激活。起始村另设一个归乡道标，方便回家训练、探望和看马，不要求把村庄改成城市。

S3 在功能原型中验证两个安全锚点；S4 用一处城门/驿站场景加归乡点呈现正式解锁，不因此新增整座城；S5 将分身覆盖所有实际制作的城池。

## 传送规则

| 问题 | 方案 |
| --- | --- |
| 能去哪里 | 已到访、已激活且当前剧情允许的安全点；未探索城池显示未知或不列入 |
| 从哪里出发 | 与城中左慈分身交互可去任意可用点；野外可在已标记的安全歇脚点用行旅符归驿 |
| 是否付费 | 解锁后免费、不消耗道具；不让省跑路变成刷钱义务 |
| 是否可逃战 | 战斗、受击、施法、Boss 封闭区、护送等限制事件中禁用；界面显示具体原因 |
| 如何呈现 | 简短选择列表/地图 → 淡出 → 加载 → 安全落点 → 淡入；重复使用可跳过已看过的长对白 |
| 能力门与主线 | 只连接已经通过探索建立的点，不越过未解锁路线或提前进入终章 |
| 状态变化 | 传送本身不重复发奖励、刷新训练次数或复制物品；恢复血量由到达驿站的恢复规则处理 |
| 失败处理 | 目标缺失/加载失败返回原安全位置，保留旧档并提示；不能落到碰撞内部 |

第一版不做野外随处瞬移、战斗中遁走或实时空间传送门。安全歇脚点布置在关卡喘息处，重要奖励后放一个归驿点，让回城整理技能不要求逆向打完整关卡。

## 坐骑是旅伴和短途便利

传送解决“城与城之间反复往返”，坐骑解决“已探索野外中的移动”和旅伴情感。二者职责不同，不能用扩大地图来证明坐骑有用。

首发安排 1 匹普通马；赤兔作为后期可选奖励候选，总上限 2 匹。是否让赤兔入首发取决于 S4 美术产能；不再加入大批名马、稀有度和抓捕图鉴。所有额外成本计入 S5 内容预算，以减少装饰或支线抵扣；若必须推迟基本骑行，需要更新此设计决定。

| 项目 | 最小规则 |
| --- | --- |
| 获得 | 一次护送/救助或主线赠予普通马，不靠概率捕捉；名马用独立小事件 |
| 使用 | 安全点选择当前坐骑，已探索的开阔野外可上下马；城内、室内、洞窟和机关区步行 |
| 速度 | 暂按步行的 1.35 倍试验；不改变探索触发可靠性和碰撞安全 |
| 战斗 | 进入战斗区域或被敌人发现/攻击时先下马，保留敌人攻击结果；没有骑乘攻击、骑马无敌或靠上下马洗伤害 |
| 技能 | 骑乘时施法输入先下马，再按步行规则决定能否施法；不把所有技能复制成骑乘版本 |
| 受伤与失败 | 不单独做马匹 HP/死亡/复活经济；坐骑回归马厩记录，玩家可再次召出 |
| 家中互动 | 后山马厩展示已获得坐骑，一次喂食/抚摸动画或短对白，允许家人照料的生活感 |
| 养成 | 没有饥饿值、每日照料、繁殖、属性刷取和马具词缀；不同坐骑主要区别外观与来历 |

移动时采用统一玩家逻辑身体，切换骑乘视觉与速度，不增加跟随寻路马队。下马必须保证当前位置可站立；狭路无法安全上下马时给提示，不强行挤出碰撞。战斗状态下无法上马，骑行冲过任务边界也必须触发下马/事件校验。

## 数据与实现边界

以下是数据含义示例，不是已存在的类：

```text
TravelProgress
  fastTravelUnlocked
  visitedMapIds
  activatedAnchorIds
  lastSafeAnchorId

MountProgress
  ownedMountIds
  selectedMountId
  completedBondEventIds
```

地图锚点、坐骑和剧情标记使用稳定 ID。左慈多个分身共用同一全局解锁进度，不能每城分别重复领取行旅符。存档不保存正在淡出的半途中间态；迁图成功并确认落点可用后才更新当前地图与安全点。

传送与骑乘属于世界/移动层：独立于技能伤害、Buff 与 Steam。DLC 若增加城市，复用相同锚点契约；DLC 缺失时回本体可用驿站并保留原记录。

## 阶段落点与验收

| 阶段 | 交付 |
| --- | --- |
| S3 | 演武场最小课程；左慈解锁标记、两个安全锚点、免费往返与存读档 |
| S4 | 解锁事件对白、归驿点、左慈分身正式视觉；坐骑只做静态样板检验规模 |
| S5 | 每城分身覆盖、南华手札与于吉短支线、普通马骑行/马厩；赤兔按产能决定 |
| S7 | 新区域加入既有传送网、少量坐骑故事候选；不默认扩成养宠或马战 |

- [ ] 解锁前不能传送；解锁后所有已激活锚点互通，未探索城池不开放。
- [ ] 从奖励点返回驿站不需逆向重打一遍；返回后仍保留有效探索进度。
- [ ] 战斗中禁传送/上马；骑马被命中不会吞掉伤害；突进/骑行/传送都不能越过剧情门。
- [ ] 多城分身共享同一进度，读档后仍生效；缺失地图可安全恢复。
- [ ] 坐骑始终辅助旅行，缺少名马不影响战斗搭配和主线通关。
- [ ] 三仙职责通过短对白可以理解，无需反复跑长链任务才能使用核心便利。
