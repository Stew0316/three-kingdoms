# RPG 原始需求与阶段映射

本附录回答用户的要求：「尽量实现 Design 里的 RPG 设计」，同时落实本次明确的核心：**主角固定为吕布，主要收集技能，不切换角色**。伙伴作为叙事 NPC；魏延可作为挑战对象。原始问题见 [2026.9.28.md](../Prompt/2026.9.28.md)，本附录不改写原始构想。

## 阅读口径

- 主来源：[RPG设计.md](../Design/RPG设计.md)；交叉核对：[RPG-base.md](../Design/RPG-base.md)。两者主要是同一组想法的不同整理形式，不重复计算需求。
- **必做**：进入相应阶段的验收；**缩小实现**：只承诺本表限定的版本；**候选**：满足下文触发条件后再排入；**延期**：首发不承诺，最早在 S7 评估。
- S0 工程与设计基准；S1 吕布对战魏延；S2 可扩展技能/Buff 内核；S3 游历、习得技能、搭配、有限训练、成长、存档闭环；S4 20–30 分钟精致切片；S5 小体量首发内容；S6 Steam 集成发行；S7 上线后内容/DLC。**S7 是评估窗口，不代表届时必做全部积压想法。**
- 用户已确认以 **单机 PvE** 为主，目前不考虑多人和 PvP；S7 也不交付联机。以后用户重新提出多人需求时，另行评估，当前不预建网络系统。固定吕布的普攻、闪避独立于技能槽；槽位提案为 3 主动 + 1 被动，仅在安全营地搭配。S1 先验证 2 个技能，S5 目标池为 8–12 个可收集主动技能及少量被动，最终数量按主阶段文档冻结。
- 定位采用「原文件链接 → 节名 → 想法编号/关键词」。`场景设计` 重复的两个「想法10」在此记为 **10A 树木**、**10B 暗洞**；`场景设计/想法34` 在主来源中是普通段落。`RPG-base.md` 的「3. 人物属性」「5. 地形」与前文粘连，因此定位以主来源节名为准，不修改原编号。

## 战斗、技能与成长

下表对应 [打击感至 Buff](../Design/RPG设计.md#打击感)、[游戏技能类型](../Design/RPG设计.md#游戏技能类型)、[人物属性](../Design/RPG设计.md#人物属性)。

| 原始点 | 结论与阶段 | 具体范围、原因与验收 |
| --- | --- | --- |
| 打击感：前摇、命中闪光、击退/硬直、动作快慢、顿帧 | **必做 S1；精修 S4** | 先让玩家看懂攻击开始、命中、恢复三个时刻，再调反馈；同一攻击只结算预期次数，顿帧结束后角色与计时恢复正常，Boss 预警始终可辨。 |
| 打击感：模糊、扭曲、血污、处决慢动作 | **候选 S4** | 只选一种确实提升反馈的效果；触发条件为基础可读性与性能已过关，关闭后仍能判断攻击范围。不能用全屏效果掩盖动画问题。 |
| 伤害设计：DamageInfo、伤害标签、方向、抗性、反伤、后置效果 | **必做 S2，分批实现** | 基础伤害、来源、目标和标签先稳定；再用正面减伤、持续伤害、反伤验证扩展。无攻击者的环境伤害可结算；双向反伤不会无限递归；一次死亡只发一次结算事件。元素种类随实际技能加入。 |
| 动作、State、TimeLine/Timeline：命令、动作时序、蓄力、加速 | **必做 S1/S2；缩小实现** | 使用实时战斗的前摇/生效/后摇与取消规则，输入和 AI 走相同施法入口；加速只影响规定的计时域。原文「本质回合制」视作时序比喻，不引入回合等待。骨骼动画是可替换表现方案，不作为阶段前置条件。 |
| Skill、AI：条件、消耗、CD、技能等级、被动效果 | **必做 S2** | 每次施法只在约定提交点扣费和启动 CD；条件失败不产生效果，取消/打断行为有定义。AI 可以直接持有技能，但仍受权限、距离和 CD 规则约束。新增组合技能不需修改伤害主流程。 |
| Buff：层数、周期、权限、驱散、施法/受击/死亡回调 | **必做 S2；缩小实现** | 先覆盖减速、沉默、持续伤害和一种增益；定义叠加、刷新、移除顺序。先做统一驱散标签，强/弱驱散待实际技能需要；不可见 Buff 不占 UI，影响操作的负面状态必须可感知。死亡与切场清理可重复验证。 |
| Buff 同时承担任务统计 | **调整实现 S3** | 任务/技能解锁读取战斗结束、击败等事件并独立存档，Buff 只维护战斗状态；验收为死亡、清 Buff、重载场景不会丢失任务进度或重复领奖。 |
| 技能想法2/3：沉默、Boss 控制抗性 | **必做 S2；缩小实现** | 时长使用可调配置；Boss 可缩短控制或具有明确免疫标签。验收为玩家能区分「未命中」「命中但免疫」，不因重复控制使 Boss 永久失去行动。 |
| 技能想法4/5/8：拉近、龙卷风、射线 | **缩小实现 S2→S5** | 作为位移、持续区域、定向伤害的技能原型；挑适合吕布及首发敌人的版本，避免每个原型都做完整 Boss。拉近后必须有可反应的预警；习得版单独配置，不直接照搬 Boss 的范围与伤害。 |
| 技能想法6/7：少量携带、技能强化树 | **必做 S3；缩小实现** | 挑战后解锁技能，有限槽位搭配；先做少量明确升级或二选一变化，不做庞大天赋树。验收为奖励仅领取一次、装配限制有效、升级与槽位存读档一致。 |
| 技能想法10/11/12；人物奋起：环绕、脚印/残影、刀光、发光 | **必做 S4；缩小实现** | 建立可复用刀光、脚下光环、短残影和状态着色方案；残影/脚印只在适合的技能上触发。高低特效档均不改变判定，受击闪白不抹掉阵营与危险提示。 |
| 技能想法1/9/13：多重施法与多周目、踏云御剑、偷技能/变身 | **延期 S7** | 多重有连锁和数值风险；飞行需要专用空间规则；任意偷取会扩大所有技能的兼容面。触发条件为基础技能池已完成且有明确玩法收益；先做白名单技能，禁止默认复制全部 Boss 技能。技能收集本身在 S3 通过奖励解锁实现。 |
| 人物属性：人物/装备分离、物理与术法；弱点、好运/好感/声望 | **必做 S2/S3；其余候选 S5** | 基础属性与技能/装备增益分开计算，先保留必要的物理/术法规则。破绽可先来自敌人后摇，独立破防条需验证其决策价值；好感、运气和声望仅在确有任务或奖励使用时加入，禁止空属性。 |

**原文语义修正记录：**`hitRate` 的原始说明是「下次必定暴击」，后续设计应使用 `ForceCritical` 等明确语义，与命中率分开；`criticalRate` 才表示概率。`DamageInfo.defender` 表示有效战斗目标，不照搬 Unity 的 `gameobject` 类型。反伤、额外伤害和 Buff 添加应通过有顺序、有上限的后置事件处理，避免回调相互嵌套。

## 世界、场景与剧情

对应 [冒险类游戏](../Design/RPG设计.md#冒险类游戏)、[世界观/角色](../Design/RPG设计.md#世界观)、[场景设计](../Design/RPG设计.md#场景设计)。

| 原始点 | 结论与阶段 | 具体范围、原因与验收 |
| --- | --- | --- |
| 中原起步、城镇连接、三分天下、沙漠/海洋/雪地/天气 | **缩小实现 S3–S5；远域延期 S7** | 首发集中一段中原游历路线，用分区场景表达连通，不建设全国无缝世界；全局地图可只展示已制作地区。换区返回落点正确，未开放区域有叙事边界；海洋、极地和动态天气不作为首发承诺。 |
| 冷兵器与术法；现代武器；所有伙伴、家人、老师、武将性格、真假 Boss/黑化 | **缩小实现 S4/S5；部分候选** | 首发选一条完整吕布旅途和少量有记忆点的 NPC，伙伴不形成角色收集/切换系统。每个入选人物至少一次行为体现立场；家人温情、离别、替身反转按主线需要选用。手枪等现代武器、所有角色支线同时落地均不默认纳入。 |
| 场景1：魔女之泉式练功处 | **必做 S3；打磨 S4，缩小实现** | S3 先一课，首发最多 3 课；所有课程共享额度，连续现实 100 分钟未锻炼恢复 1 次，并受章节累计成长上限约束。南华用手札/传闻引入；训练教授走位与搭配，离线计时，不做每日任务。验收无收益复练重新计时、存读档不重复结算、未训练仍可通关。详见 [锻炼规则](设计-锻炼收益与实际时间.md)。 |
| 场景27/29：回乡、吕布自省 | **候选 S5** | 最多先选一个短事件表达成长，奖励一次性，进度存档后不可重复领。回乡若采用家庭关系，先统一它与吕布架空身份的设定。 |
| 场景2/9：驿站/客栈、恢复、铁匠、杂货、医馆、马厩、镖局 | **缩小实现 S3→S5** | 驿站承担恢复、整备和出发；基础补给按闭环需要加入。铁匠可先是升级交互，不必为每项服务做独立建筑；马厩、镖局随对应玩法决定。验收为一次出门挑战、习得/成长、回站整备能完整循环。 |
| 场景3/4/30/31：坐骑、宠物、七马赛马、后山马厩 | **坐骑缩小实现 S5；赛马/养成延期** | 宠物方案替换为三国坐骑：1 匹普通马，赤兔候选，总上限 2 匹；只在允许区域辅助非战斗移动。无养成数值表、马战、赛马和马厩收集系统。验收为上下马位置合法、战斗触发可靠、坐骑拥有状态可存档，不改变技能成长主线。见 [坐骑与三仙传送](设计-坐骑与三仙传送.md)。 |
| 场景5/6：护镖/劫镖、夜间镖局任务 | **候选 S5；缩小实现** | 如入选，仅一段手工制作护送事件；昼夜用该场景的固定时段表达。目标失败可重试、伏击有提示，不加无限押镖经济循环或全局时钟。 |
| 场景7/13/17：守护武器、名兵、武器出场 | **候选 S5** | 选一件符合吕布身份的奖励，用一次短演出强化获得感；奖励可关联技能/升级，不发展十大神兵收集线。验收为拾取、解锁、演出跳过和读档一致；具体名称与素材独立设计。 |
| 场景8/10A：卖艺围观、桂花/樟树/地标大树 | **缩小实现 S4** | 作为城镇辨识与氛围模块，先完成可复用树木和一小组背景互动；不要求每座城都有专属系统。验收为地标能帮助找路，环境不遮住角色与交互提示。 |
| 场景10B/26：暗洞、火折子、暗河捷径 | **候选 S4/S5；缩小实现** | 切片若选洞窟，做一个照明开关与一条可回到旧区域的捷径；火折子一次获得，亮灯状态保存。验收为缺少火折子也不会卡死主线，打开捷径后往返路径确实缩短。 |
| 场景11/12：卖艺赚钱、感谢信/邮箱 | **候选 S5** | 来信可先实现为事件后新增的一条可读记录；卖艺小游戏延期，关键补给不能依赖它。触发条件为剧情确需该表达，验收为阅读状态和奖励持久化、不会重复触发。 |
| 场景14/15/32：擂鼓、千军万马、一次攻城结局与器械 | **延期 S7** | 兵群、器械和专用演出成本大，不取代首发游历结局；先用小规模关卡验证，是否成为 DLC 另作决策。首发可用已有场景/文字交代背景战事，不承诺实时大军模拟。 |
| 场景16/18：道路受阻、开局强敌 | **必做 S3 的路线门槛；强敌候选 S4** | 门槛由任务或挑战解锁，必须有明确提示；可选强敌要有绕行/返回路径与合理失败代价，不能堵住教程。读档后解锁状态保持。 |
| 场景19/20、角色龙：龙影、高速掠影、隐藏龙 Boss | **掠影候选 S5；龙 Boss 延期 S7** | 先验证一段短背景暗示，不承诺非人形 Boss 的整套美术与碰撞。龙 Boss 只有在扩展包主题成立、独立体型与技能预算通过时进入制作。 |
| 场景21/22/23/25：登场、下降、蒙面、气势 | **缩小实现 S4** | 选择一个保留当前 2D 视角的 Boss 登场，复用镜头移动、停顿和冲击波；不新建第一人称演出管线。可跳过、重复挑战不过度拖时、演出结束控制权恢复。 |
| 场景24：左慈/于吉演讲、追杀、监牢、行刑与救援 | **三仙缩小实现 S3–S5；完整分支延期 S7** | 最新定位：南华引入训练，左慈承担分身传送，于吉只做一条短支线或术法奖励；可以书信/传闻表现，不同时扩成三条人物长线。演讲、通缉、监牢与救援大分支不纳首发。剧情条件、传送解锁和一次性奖励可存读档验证。 |
| 场景28/33/34：比武大会、星图术法、吕布双路线 | **星图表现 S4；其余延期 S7** | 星图先用于技能界面和视觉母题，不隐含占星/昼夜模拟。完整大会与双路线会放大关卡和叙事量；需现有主线完成、复用成本清晰后单独立项。 |

## 地形、界面与兵种

对应 [地形](../Design/RPG设计.md#地形)、[菜单](../Design/RPG设计.md#菜单)、[兵种及类型/克制关系](../Design/RPG设计.md#兵种)。

| 原始点 | 结论与阶段 | 具体范围、原因与验收 |
| --- | --- | --- |
| 地形1/2：湖水/瀑布 Boss 战、绕山战、分身喷火 | **候选 S5；专用运动规则延期** | 如入选，先用普通可行走平台搭景，复用已验证技能；不增加游泳或圆柱空间移动。水面视觉与实际可走区域一致，边缘不会误导玩家。 |
| 地形3/14：出生村、后山瀑布、种菜钓鱼 | **村落缩小实现 S3/S4；生活玩法延期 S7** | 出生村服务教程与恢复；后山或瀑布按切片预算选一处地标。种菜、钓鱼、宠物养成不承担首发成长来源。 |
| 地形4/13：城市传送、雕、全国图、室内/二层、小地图 | **传送必做 S3→S5，其余缩小实现** | S3 两端最小传送；S4 演示左慈剧情节点开启传送；S5 各已制作城市有分身点。城市必须先亲自到达并激活，剧情开启后才互通，不解锁未探索城市。用分身网络取代飞行宠物；房间切场与区域地图按需要制作，全国实景和大量楼层延期。验收为未解锁点不可选、返回落点合法、状态可存档。 |
| 地形5/6/16：山谷、山洞、矿洞材料 | **山谷/山洞跟随入选关卡；采矿候选 S5** | 复用地形素材拼出不同路线；矿洞先作为探索奖励点，不额外构造材料生产链。若没有已入选的装备升级消耗，就不增加矿产资源。 |
| 地形7/11/12：水车、桥、码头、城镇、自然曲线路径 | **缩小实现 S4** | 形成一套中原城镇/郊外素材和构图规则；优先桥、树、屋顶等易辨认元素。道路有自然变化但行走边界清楚，转角与遮挡处仍能辨认吕布位置。 |
| 地形8/9：边缘提示、上下衔接、区域块状与城池线性 | **必做 S4** | 主路线清晰，至少一处提前可见、绕路可达的区域和一处打开后可返回的连接；验收时玩家能解释「刚才看见的地方怎样到达」，地图不是只有装饰的走廊。 |
| 地形10/15：囚禁、战乱、兵营、篝火、白骨 | **缩小实现 S4/S5** | 选少量环境叙事物件体现战乱，维持整体色彩与交互语言；视觉展示不默认派生监狱/营地管理系统。能交互的对象与纯背景须区分。 |
| 菜单：吕字战旗、烟火、水墨长卷、地图入口 | **功能 S1/S3；风格 S4；适配 S5** | 先可用，再应用统一战旗/纸卷风格；地图、技能搭配等高频入口独立快捷访问。烟火不遮文字，手柄焦点清晰，简中/繁中/日文/英文均无关键文本截断。 |
| 兵种：枪、盾、弓、朴刀与克制 | **缩小实现 S4/S5** | 用近战基础兵、持盾和远程等有辨识度的行为组织遭遇，再按预算扩充枪兵。优先体现盾挡正面箭、绕后破防、弓手脆弱等可读规则；不直接把原文全部相克转为隐藏伤害倍率。验收为玩家仅凭动作与装备能判断应对方式。 |
| 兵种：骑兵、重骑、怕火、大量单位 | **延期 S7** | 骑乘动画、冲锋碰撞和大量单位性能单独评估；只有关卡真的需要快速冲阵或重甲单位时才增加，不能仅为凑齐分类而制作。 |

## 候选进入制作的条件

1. **到期不自动转必做。** 候选只有在依赖阶段通过后才评审；例如 S5 支线必须建立在 S4 切片已完整可玩、技能与存档验收通过的基础上。
2. **逐项写清四件事：**给核心游历/战斗带来什么收益，需新增哪些资源/规则，预计工作量，替换哪项同等或更大工作量的可选内容。不能以「以后可能用到」为理由增加框架。
3. **先验证最大不确定性。** 首次原型只做最小可玩片段；若不能复用现有战斗、交互与存档结构，先退回延期列表。可读性、存档正确性和帧耗不能为候选让步。
4. **入选即补验收，未入选不阻挡发行。** 写出成功、失败、重复进入、存读档四种结果；S5 内容冻结后，新增愿望默认放回 S7 评估。付费 DLC 也需独立成立的内容价值，不把基础剧情或修复项预先拆出去。

首发力保的是「吕布游历 → 挑战 → 获得有想象力的技能 → 选择搭配 → 再挑战」及统一、清晰的 2D 表现。原文保留下来的大型愿望有明确去处，但不共同占用首发承诺。
