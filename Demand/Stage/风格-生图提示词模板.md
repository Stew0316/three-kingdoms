# 生图提示词模板

更新：2026-10-17。与 [正式风格指南](../../Source/StyleGuide/城池与地形风格指南.md) 配套使用。模板提供可复用的结构，具体对象的尺寸、视角、材质和精度由用途决定；不再统一限制为像素画、固定头身或少量细节。

## 使用方法

先明确资源是概念参考、独立素材、角色拆件还是正式图集，附上实际使用的参考图。展开所有占位符再生成，记录完整提示词和返回结果。静态动作研究不等于可播放动画，整张场景图不等于可交互地图。

## 共用前缀

```text
为三国题材的二维俯视游历与即时战斗游戏制作<资源用途>。
时代依据为三国时期，结合<地域、身份、用途和已核对资料>，统一色调、建筑、衣物与生活器物。
保持参考中的视角、角色身份、比例、材质和光照。人、动物与建筑的结构和连接真实可信；动作符合对应现实对象的重心、支撑、接触和惯性。
按实际需要精细制作<材质、关节连接、服饰、建筑构件等重点>，同时确保游戏展示尺寸下的层次和可读性。
对象：<名称和用途>。素材尺寸：<本次尺寸>。游戏显示尺度：<实际尺度>。
输出：<透明独立素材/独立背景/布局明确的图集>。完整保留轮廓与必要边距。
参考图：<逐张说明身份、结构、视角或材质用途；说明有效版本>。
```

## 人物与动物

```text
[共用前缀]
人物或动物：<身份/物种、体形、面部、衣甲或毛色、装备>。
姿态与朝向：<方向、承重部位、重心、关节状态、手脚或蹄的接触关系>。
若持械或骑乘：<武器尺寸和握位、鞍座、缰绳、脚部支点及对应受力>。
服饰、披挂、鬃尾和附件有清楚连接，材料厚度与褶皱符合动作和重力。
不新增肢体，不裁断头部、兵器、手脚或尾部；保持所有部件属于同一对象。
```

拆件图额外写明网格、每格名称、主轴和关节端覆盖区，按实际模型绑定设计。近远部件的解剖方向、骨长和采样边界一致。不要把整个人物、地面阴影或相邻零件烘焙进单个拆件；静态拆件不负责实现动作时序。

## 建筑、地形与公共景物

```text
[共用前缀]
建筑或景物用途：<驿站/军营/铁匠/民居/马厩/道路/树木等>。
时代与结构依据：<已核对的三国时期依据；游戏化部分单独说明>。
尺度：<与人物、马匹、门窗、道路的关系>。
结构：<屋顶、梁柱、墙基、门窗、台阶、附属空间>；支点、承重与接合完整。
材质与细节：<瓦石、木构、金属、土墙、织物、磨损与使用痕迹>。
陈设与空间：<工具、储物、灯具及其挂点>；保留实际工作、交互和通行空间。
统一俯视高度和光向，地面、立面和屋顶的透视一致。
```

建筑图集逐格指定用途和差异，悬出的屋檐、灯具和树冠须有独立空间。正式字牌由引擎排字，生成图不使用乱码充当标识。地形源图若需平铺，明确接缝和过渡规则，并在引擎拼接后检查。

## 特效、图标与立绘

| 资源 | 提示词必须补充的内容 |
| --- | --- |
| 刀光 | 对应武器、挥舞方向、阶段、轨迹、透明范围与原点；不能用静态光效改变伤害范围。 |
| 状态光环 | 状态用途、地面投影、中心、轮廓和节奏；与危险提示有形状区别。 |
| 技能/物品图标 | 核心意象、正式显示尺寸和缩小后的辨识要求；文字、冷却、边框由 UI 装配。 |
| 人物立绘/头像 | 与游戏内身份、脸部、衣甲和装备一致；构图、表情、裁切安全区单独指定。 |

立绘、图标、图集和场景需要不同构图，不以同一组画布和头身要求套用全部对象。

## 记录与验收

每批保留：资源 ID、用途、风格版本、输入参考、完整提示词、工具实际返回的模型信息、请求及实际尺寸、源文件、修改文件、正式文件、透明与锚点检查、实际接入状态。未知信息写明未知，不补造 seed 或模型版本。

生成后核对身份、时代依据、结构、动作、比例、视角、材质、光照与完整边缘。在实际游戏尺寸和背景下检查，并对图集逐格验证。新版本另存，原图保留；通过对应功能与视觉验收后再登记为正式资产。

本模板来自 [本轮需求](../Prompt/2026.10.17-项目结构整理与三国自然风格规范.md)。已生成素材的原始提示词留在 `Demand/美术` 或对应历史需求中，作为历史证据，不自动成为后续制作约束。
