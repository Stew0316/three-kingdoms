# 吕布向下站姿与骨骼动作：V2 站姿校准

当前手臂素材与绑定已更新为[V3内袖与肩甲分层](LvBuDownArmStructureV3.md)，本页保留V2手位、脚距与验收记录。

日期：2026-11-02。V2状态：在第一版八种动作基础上，按用户再次提供的正面参考校准双手与脚距；修正版800帧实际图形运行检查通过，供用户查看观感。沿用独立方向组件的制作方式，四向自动选图尚未接入默认游戏角色。资源文件名保留V1以维持现有引用，新预览单独保存至 `Build/LvBuDownV2`。

## 用户要求与制作依据

用户要求：“先组回完整站姿，校准关节和遮挡，然后参考向上和向右方向的吕布继续完成动作”。

后续反馈：“跟这个效果差好多啊，吕布拿戟的手的位置不对，另一边手位置也不对，然后脚要张开一点”。该反馈取代第一版站姿的视觉结论；原图仍使用下述已确认的正面参考。

造型使用已确认的 [向下站姿](../../Source/People/Portraits/LvBu/LvBuDownFacingV1.png)，采样 [主拆件页](../../Source/People/LvBu/LvBuDownPartsV1.png) 与 [双腿兵器页](../../Source/People/LvBu/LvBuDownLegsWeaponV1.png)。动作组织、真实战斗时钟、双手握柄和连续预览沿用 [右向](LvBuRightRigV1.md) 与 [背面](LvBuBackRigV1.md) 的制作方式；向下单独校准姿态与遮挡，不沿用背面的部件顺序。

本轮没有重绘原图，未使用三维建模。纵深只是既有二维骨架的关节求解与投影，世界移动、碰撞和战斗仍为二维。

## 本次校准

- 画面右侧的持戟手移至腰部外侧，站姿握点从 `(30,-39)` 调至 `(35,-39)`；降低手部纵深，独立校准屈肘方向，使上臂落在肩侧，小臂斜向下连接手腕，消除原先横挡腰部的轮廓。
- 画面左侧空手向外、向下调整至 `(-28,-29.8)`。自由臂的固定前臂链长校准为21.5，原为20；它包含掌心偏移，动作过程中没有伸缩骨长。肩肘腕顺着身体侧边连接。
- 脚点从左右各11调至各14，总脚距22→28，增加约27.3%。站走、攻击、闪避各关键姿态使用相同横向落脚位置，起收势不再收回旧脚距。
- 行走和闪避的持戟手、所有姿态中的自由手起收位置同步调整；持柄约束与原有技能时钟保持一致。
- 空手移开后暴露出前臂采样框中的邻接披风碎片，使用该图集格的独立排除区隐藏；保留原PNG与腕部锚点。
- 共用模型新增两臂屈肘参考向量和按图集格排除邻件的配置，默认值保持旧行为；本次已回归右向、背面各800帧。系统合同见[二维骨骼架构](../../Architecture/08-二维表现与角色骨骼架构.md)。

## 站姿、关节和遮挡

- 人物解剖学左手对应画面右侧并持戟，右手在画面左侧自然下垂。骨架业务“远手”在本模型中承担左手主握点，“近手”承担右手自由/辅助握点，不按业务名称猜测画面左右。
- 共16个业务关节，另有2个独立靴掌和7个附属层；主冠翎业务贴图隐藏，双翎分别采样原图。实际可见层为24层；备用手、侧后裙片及独立武器备件没有全部重复叠上去。
- 头身、胸腰与披风分别配置显示比例。胸甲裁区去掉原图已包含的下方腰扣，独立腰带覆盖连接处；前裙甲置于腰带后、腿前，肩甲随对应上臂，领巾覆盖胸甲领口。
- 披风在身体和手臂后方，双翎在头发后，冠座在头发前。长戟先绘制、双手后绘制；向头后提戟的阶段使用既有动态遮挡，避免杆身直接盖住脸。
- 肩肘腕、髋膝踝按各自源图轴线标定；左右腿脚按独立区域采样。缩小手部采样窗口，排除源图重复护腕，原图本身不裁改。
- 右手站立目标略下移，减轻肘部弯曲。主握点与副握点来自同一杆轴；保持真实骨长，在纵深求解后投到二维，原图的投影缩短不等于改变骨长。
- 双翎根部留距，形状与摆幅不同，分别随风变化；披风只在移动中产生更明显摆动。暂停时共用角色表现时钟冻结。

实际数值和原图坐标以模型与动作资源为源；源图规格、提示词和原始校验见 [拆件记录](LvBuDownPartsV1.md)。

## 动作内容

| 状态 | 表现 |
| --- | --- |
| 待机 | 左手侧立持戟、右手放低；胸部轻微呼吸，脚点固定，双翎独立风动 |
| 行走 | 向画面下方交替落脚，纵深屈膝、重心随承重变化，右手小幅摆动 |
| 挥戟 | 先提戟、右手接柄，再从上方向前下方挥出并收回；起手的手部纵深用于避开过度折肘 |
| 横扫 | 双手持杆、胸腰小幅配合，从蓄势扫向前侧；调整接柄距离和纵深，避免副手缩到肩旁 |
| 突刺 | 在身体前侧提稳兵器再向下方向推出，投影适度缩短；主握手下移，避免前臂投影过短和杆尾遮脸 |
| 闪避 | 沉胯护住兵器，结束后连续收回站姿 |
| 反击 | 从当前姿态进入本方向挥击曲线，随后回架 |
| 受击 | 上身与自由手缓冲，脚点与站姿连续恢复 |

动画读取原有技能阶段，没有修改伤害、冷却、位移速度或判定范围。预览角色保持居中，地面线读取真实位移滚动，便于观察接地。

## 验证与边界

编译零警告、零错误。Godot 4.7.1、D3D12 Forward+实际渲染检查包含800个连续动作采样，另录制120帧待机风动；源码入口为 [LvBuDownPreview.cs](../../Scripts/Tests/Animation/LvBuDownPreview.cs) 与 [风动检查](../../Scripts/Tests/Animation/LvBuDownPreview.Wind.cs)。

| 检查 | 最终结果 |
| --- | --- |
| 主手握点误差 | 最大0.000071骨架单位以内 |
| 完全接柄后的副手误差 | 最大0.000234骨架单位以内 |
| 源图肘、腕锚点接缝 | 最大0.000397骨架单位以内 |
| 真实肘部弯曲范围 | 约22.55～144.88°，通过18～148°制作约束 |
| 世界承重脚单帧滑动 | 最大0.000062世界单位以内；68次稳定承重段比较 |
| 足底离地误差 | 承重段0；固定骨长与落脚目标检查通过 |
| 绘制顺序 | 披风在身体后、双手在杆前、冠座在头前、双翎在头后，800帧逐帧检查通过 |
| 暂停与顶墙 | 动作/布料时钟冻结；顶墙停止累计步态路程，移动引起的布料摆动收稳 |
| 双翎实机风动 | 固定挂点后左右分别有12640、8179个像素变化；两个根部7×7区域变化均为0；暂停像素一致 |

详细证据：[动作量测](../../Build/LvBuDownV2/MotionAudit.json)、[风动量测](../../Build/LvBuDownV2/WindAudit.json)、[最终渲染日志](../../Build/LvBuDownV2/MotionRender.log)。暗底、浅底和攻击关键帧已目视检查，未发现重复护腕、透明矩形底或明显关节断开。动画观感仍以用户后续反馈为准。

本轮扩展共用模型的可配置屈肘方向和图集排除区，默认值保持旧行为；右向、背面各800帧无图形回归通过，报告分别保存在 `Build/LvBuDownV2/RightRegression.json` 与 `BackRegression.json`。旧V1视频和截图仍保存在原目录。当前没有新增向下专用死亡、骑乘或跳跃片段，也没有完成四方向自动切换；不能把独立方向组件写成默认角色已经换成四向。

## 复现

在Godot中打开上述制作台按F6。批量验证时使用项目现有的Godot .NET版本：

```powershell
dotnet build Three-Kingdoms.csproj --no-restore
& 'G:/Godot/Godot_v4.7.1-stable_mono_win64/Godot_v4.7.1-stable_mono_win64_console.exe' --path . --fixed-fps 60 res://Scene/LvBuDownPreview.tscn -- --capture-lvbu-down
```

无图形约束检查使用 `--headless` 和 `--test-lvbu-down`。`--idle-only`仅验证40帧站姿，不能代替完整动作验收。视频和动图由连续运行截图编码，入口见 `Build/LvBuDownV2/EncodePreview.ps1`，不重新绘制角色或另行制作预览动画。
