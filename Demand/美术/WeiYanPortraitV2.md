# 魏延绿色披风立绘 V2

生成日期：2026-10-25；更新日期：2026-10-26。状态：用户已确认 V2，立绘统一归档至 `Source/People/Portraits`。当前 UI 采用 V2，并据此完成独立透明拆件与骨骼动作，见 [魏延 V3 制作记录](WeiYanRigV3.md)。

## 用户要求与本轮修正

- 参考 [吕布立绘](../../Source/People/Portraits/LvBu/LvBuPixelReference.jpg) 的人体比例，魏延采用绿色、有披风、不戴凤冠。
- 第一版采用非像素手绘。用户反馈人物风格差异过大，明确修正为：魏延应粗犷，但整体画风与吕布接近，只在人物造型上区分。
- V2 以用户提供的吕布原图作为唯一画风和比例参考，采用大头、宽肩、紧凑四肢、粗黑轮廓与复古像素彩绘质感。魏延通过短络腮胡、低铁盔、绿色衣甲、披风与长柄刀形成区别。
- 用户随后确认“对就是这样”，并要求统一整理立绘、据此重做魏延外观和骨骼动画，特别避免异常扭曲角度。该范围已延伸至魏延运行时，其他武将保持各自造型。

V2 为单图、单人物、单视角，无图集格序。整图采样窗口为 `(0, 0, 1254, 1254)`。人物、双靴、披风和长柄刀均在画面内。背景是画面内容，V2 用作 UI 立绘，角色移动使用另行生成的 `WeiYanPartsV3.png` 透明拆件；旧 `weiyan-parts-v2.png` 保留归档，当前模型已更换至 V3。

装束与长柄刀是以汉末三国气质及札甲材料为启发的游戏化造型，不作为历史复原结论。

```text
用途分类：stylized-concept。
任务：参考输入图1，创作同一游戏、同一美术师、同一套画风中的魏延全身立绘。用户纠正：人物要粗犷，整体画风和吕布基本一致，差异只在角色长相、服装、配色和装备造型。

魏延：成年中国猛将，约3.5至4头身；头部从头发顶到下巴占人物总高约四分之一至近三分之一，肩宽和厚手臂比例贴近吕布。比吕布更粗犷：宽阔方脸，略宽的鼻子，浓黑粗眉，锐利大眼，结实的颧颊，短髭和浓密但短的络腮胡。胡须以清楚的大色块和少量像素束表现，不画写实毛发，不画关羽长须。表情刚猛沉稳。
造型：黑发收束于简洁低矮的青黑色铁盔内，铁盔略露发际和鬓角，额部用一圈旧铜边，头上绝对没有凤冠、双翎、羽毛、长缨或高大冠饰。厚重而简洁的分层札甲护肩，与吕布肩甲轮廓有区别；深铁色甲片配大块墨绿衣袍、绿色甲裙，少量旧铜包边和深棕皮带。采用与参考图相同的概括细节密度，避免遍布细小铆钉和超写实金属磨损。衣物完整、略有磨损，不能做成满身破布。
披风：醒目的深绿色披风，有明确双肩挂点，从背后垂至小腿并向一侧轻轻展开，厚重自然的少量大褶皱，保持完整边缘，不变成围巾。绿色是人物鲜明主色，但保持古朴、低饱和、冷峻的基调。
动作与武器：一个完整的站立魏延，略三分之四朝向画面右侧，双脚踏实站稳。一手在腰侧自然握住朴素长柄单刃大刀，刀刃朝上，整把刀在身体侧方斜立，与吕布的方天画戟不同；另一手自然握拳下垂。手指包住刀杆，关节和握持可信。刀不挡脸。
构图：尽量采用方形画幅。单人、单视图，头顶、披风、两只靴子和整个刀全部入画，四周留白。人物视觉上必须明显是参考图的粗壮大头比例，不能因全身构图拉长身体。
背景：沿用吕布参考图的浅米灰旧纸底、极淡灰墨远山气氛，背景很淡很简洁，以人物为主；不要黑色光晕背景。没有马，没有其他人物，没有展示台，没有名称、文字、标签、水印或边框。
最终自检重点：与参考吕布同一套画风及比例；魏延粗犷短须；绿色衣甲和披风；无凤冠；清楚的复古像素彩绘质感。
```
