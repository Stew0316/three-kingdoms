# 三国游历

基于 Godot 4.7.1 C# 的二维俯视游历与即时战斗游戏。当前可玩内容包括槐安城、四人演武场和旧驿道洞窟。

## 运行与验证

使用 Godot .NET 编辑器打开 `project.godot` 并构建 C# 项目。正常运行由 `GameEntry` 进入槐安城；引擎命令行自定义参数 `--arena` 进入演武场，`--cave` 预览洞窟。

构建可使用 `dotnet build Three-Kingdoms.csproj`。各专项回归的入口和用途见 [当前实现索引](Architecture/当前实现索引.md#验证入口)；截图、运行日志放在 `Build`。测试命令存在不等于本次已经执行，具体执行环境、结果和遗留项记在对应需求文档。

## 文档分工

- `AGENTS.md` 保持简短，只记录长期规则和一级目录职责。
- `Architecture` 解释代码组织、依赖边界与运行机制；实现索引区分现状、限制和提案。
- `Demand/Prompt` 保存用户问题及当次决定，`Demand/Stage` 保存阶段计划，`Demand/美术` 保存生成和接入记录。
- `Source/StyleGuide` 定义当前视觉标准；资产索引标出实际使用版本，历史素材保留追溯。

历史文档按当时背景阅读，后续明确需求优先。文档更新不代表已有资源完成重绘，也不代表原有验收自动覆盖新改动。
