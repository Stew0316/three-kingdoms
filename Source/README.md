| 位置         | 内容                                                                                                 |
| ------------ | ---------------------------------------------------------------------------------------------------- |
| `Animals`    | 动物原图与拆件候选；是否接入由对应资源记录说明。                                                     |

| `_downloads` | 第三方下载的原始压缩包与帧图归档，只做仓库留档。目录内有 `.gdignore`，Godot 不扫描、不导入、不导出。 |

工作室通用 Logo 放在根目录 `BaseSource`。猫头鹰亮/暗背景候选均保留原图，说明见 [Logo 生成记录](../Demand/美术/猫头鹰Logo生成记录.md)。

`_downloads` 下的文件不能通过 `res://` 访问，也不会生成 `.import`。需要正式接入时，把选中的图片移到 `Animals`、`People`、`City` 或 `Terrain` 的对应目录，由 Godot 重新导入并记录版本与验收。

## 槐安城图集

当前使用 `City/HuaiAn/huai-an-buildings-qingming-v2.png`，1536×1024 透明 RGBA；v1 保留。三列两行依次为驿站、军营、铁匠、民居、马厩、国槐。该图按 2026-10-13 的参考方向制作；2026-10-17 改为三国时期整体依据后，本轮仅修订规范，没有重绘图集。

`CityArtAtlas` 先使用独立窗口隔离相邻物体，再根据透明边界收紧；部分檐角跨过均分线，不能直接六等分。`CityBuilding` 绘制建筑及独立的酒幌、锤形标、交叉刀剑门饰，字牌由引擎排字。纹理里已有灯具时不再叠画同一盏。

原图、格序、采样窗口和接入验收见 [图集生成记录](../Demand/美术/2026.10.13-槐安城古建筑图集生成记录.md)。图片外轮廓不作为碰撞数据，更换图片后仍需核对建筑落地点、足迹、NPC 和交互范围。

## 马匹素材状态

马匹完整场景及可拆用的动作、骨架、外观与骑乘连接位于 `Components/Mounts`；枣红/青骢预设引用以下原图，未复制另一套素材。直接使用与独立预览见[组件说明](../Components/Mounts/README.md)。

两张V2原图采用Mipmap缩小采样，所有皮肤共用细节偏置−0.4的材质，以减少移动时毛发/斑纹闪动并保留小尺寸轮廓；原图像素未改写。显示节拍、采样对照与验收见[卡顿与发糊修复](../Demand/美术/2026.10.18-骑乘移动卡顿与发糊修复.md)。

当前绑定 `Animals/Horses/horse-chestnut-parts-v2.png` 与 `horse-dapple-parts-v2.png`，两图均为1536×1024透明RGBA，V1原图保留。V2每图包含整身颈头、完整前腿、完整后腿和尾部四件，运行时为整身、尾、四条含蹄连续腿和原图鞍具表层共七张网格；32个骨骼控制/连接节点保留。远腿在整身后绘制并压暗。2026-10-19将整身原图的肩/臀肌肉重新绑定到上臂/股骨，末端与肘/膝重合；近腿只在上段末尾重叠衔接，鞍具覆盖活动肌肉。骨链、步态和采样清晰度保持原实现，具体标定与图像证据见[肩胯蒙皮修复](../Demand/美术/2026.10.19-马匹肩胯蒙皮衔接修复.md)。

动作参考Muybridge第621图版，保留三拍落蹄、定长骨链与世界接地，缩短回收阶段并调整腿段比例。采样窗口、源锚点、原始提示词及本轮验收见[V2制作记录](../Demand/美术/2026.10.18-拟真马V2制作与验收.md)。实际仍是左右侧身镜像，尚无八向独立马图；不能把八方向移动检查等同于八向美术完成。
