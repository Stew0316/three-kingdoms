# 城池与地形风格指南

版本：1.3。更新日期：2026-10-14。适用范围：本项目城池、村落、道路、城郊地形、洞窟、公共景物及相关建筑美术。首个落地对象为槐安城。

## 阅读与使用

按用户要求，AI每次开始任务都先阅读本指南，再按实际工作范围遵守适用章节；纯数值、战斗逻辑等工作无需为此改动现有美术。用户后续明确的新要求优先，发生方向调整时同步更新本指南、`AGENTS.md`摘要及`Demand`需求记录。

本指南描述应遵循的设计规则，不证明某张候选图已经完成、接入或通过测试。资源实际状态、生成提示词与验收证据分别保存在对应生成记录及需求文档中。`Source/StyleGuide/S0`中的历史草样仍是候选参考；城池和地形的后续工作以本指南和用户最新要求为准。

## 1. 统一的视觉方向

**建筑和地形采用《清明上河图》的古城市井气质，建筑大小、人物与门屋的比例、地图可读性参考《宝可梦 火红／叶绿》。**

游戏题材仍是三国游历。取《清明上河图》的木构、瓦屋、街市、草岸、树石、道路与生活气息，不做严格宋代城池复原；下文屋顶和灯具名称用于指导造型，不是具体年代或形制的历史断言。黑神话悟空只辅助理解传统木构、檐口与屋顶的体积，不采用写实级雕刻、暗沉气氛或巨大殿宇。

| 方面 | 统一要求 |
| --- | --- |
| 视角 | 二维俯视，屋顶加可读正面立面，保持现有TileMap和八方向移动；所有房屋、灯笼和器物使用同一俯视高度 |
| 规模 | 小城、小屋、短街；普通房屋以数个人物宽度构成，压缩现实进深和高度，门口、人物、马匹仍容易看清 |
| 造型 | 大轮廓明确，少量中等尺度细节；屋顶、门窗、檐棚和招幌先于瓦片纹样；缩小后仍能辨认设施 |
| 配色 | 暖土、灰青、木褐、低饱和草绿为底；赭红和少量暖白作识别点，不把每间屋子染成一种鲜亮颜色 |
| 光照 | 全城统一柔和昼光与阴影方向，明暗克制；灯笼和炉火局部温暖，不能形成盖住角色的大光晕 |
| 画面层次 | 角色与交互点优先，建筑提供轮廓和功能识别，地面更低对比；不让瓦片或草纹成为最抢眼部分 |
| 题材气氛 | 能生活、能整备、能游历的三国小城；木料、布幌、瓦土和器物有合理使用痕迹 |

皇家金顶、通体朱漆、巨型飞檐、层叠斗拱和庙宇式宝顶仅适合后续有明确身份的特殊地标，不能作为首城普通设施的默认造型。既有人物风格和功能标识不因环境参考变化而随意改换。

## 2. 建筑必须有真实的差异

用户希望“尽量不一样的地方多一点”。每栋建筑先确定用途、体量和生活方式，再选择差异。相邻房屋应在**屋顶轮廓、入口结构、附属空间**中至少两项有明显区别，并辅以灯具、窗棂或陈设差异；不能仅复制房屋后随机换色。

屋顶差异必须落到轮廓上：同时比较屋脊高低、坡面长短、檐口直曲、出檐深浅以及附棚的材料和高差。飞檐只作少量轻挑，檐下能看见支柱、横梁或托撑；不能仅在同一屋顶上改几条瓦线，也不能用浮空的檐角代替完整檐口。新增建筑先与相邻建筑比较大形，再确定独有的入口和招牌，不要求每间屋子拥有所有装饰。

| 部位 | 可变化的方式 | 必须保留的共同规则 |
| --- | --- | --- |
| 屋顶形制 | 短歇山、高脊悬山、平直硬山、轻单坡；附棚可用卷棚，局部搭茅顶 | 檐角适度、瓦屋有重量，透视和坡面受光一致；“混合”指主屋和附棚组合，不将不相容结构挤在同一顶上 |
| 材料与新旧 | 深浅灰瓦、局部补瓦、旧瓦苔痕、木板、茅草或苇席附棚 | 旧不等于废墟；残瓦和磨损以少量大块表达，不用密集破损制造噪声 |
| 屋脊与檐口 | 脊高、长短、直檐或轻扬檐、露梁、短檐或深檐 | 不给所有房屋同一套飞檐；伸出屋檐不能遮住重要NPC或让墙体碰撞边界难判断 |
| 层数与高低 | 普通单层、稍抬高主屋、前低后高、附棚错层；少量视觉夹层 | 首城以单层为主；高低差帮助识别，不因显示多一层就暗示已实现可进入二楼 |
| 灯笼和灯具 | 圆、椭圆、方、长筒、竹编或铁框；暖白、素黄、低饱和赭红；单只、成对或无灯 | 灯具差异由用途决定，形状和挂法一起变化；大小适合檐下或门旁，不挡门，不把所有门口都装一对红圆灯 |
| 挂灯位置 | 门两侧、檐角、附棚梁下、工作台上方、围栏柱头 | 绳杆和支点有依附，落点不悬空；入口和行走轮廓优先 |
| 大门 | 窄单扇、宽双扇、竹帘、布帘、敞开铺面、栏门；简短门罩或小门楼 | 门洞清楚，门槛和道路接得上；门楼克制，不能借装饰把普通屋门放成宫门 |
| 窗棂 | 竖木条、疏方格、横窗、木百叶、半开板窗、窗下小架 | 少而清楚，服从立面结构，不将极细复杂纹样平均铺满各屋 |
| 墙体 | 浅土墙、露木柱、夯土基座、少量灰砖、局部补灰与烟熏 | 土木材料为主，材料过渡有结构理由，色彩同属暖土与灰青体系 |
| 台阶与门前 | 一两级石阶、低土台、木踏板、平地开口、短廊 | 高低与屋内地面一致；显示台阶不意味着改变碰撞或增加不可走高度 |
| 招牌与布幌 | 横木牌、侧挂长幌、窄旗、器物标志，布料可有长短和磨损差异 | 功能可辨、文字由游戏清楚显示；生成图中的乱码不能当正式字牌使用 |
| 生活陈设 | 水缸、竹筐、柴垛、木箱、凳案、工具、饲槽、草束、马具 | 每栋选少量与用途有关的器物；让门前留有空间，不堆满道路或复制同一组箱桶 |

## 3. 槐安城五栋建筑差异表

下表是首城的具体制作目标，不是历史复原规格。屋檐、灯具、门面和陈设需组合形成用途，而非单独随机分配。

| 建筑 | 屋顶与体量 | 灯具与悬挂 | 入口、窗墙与台阶 | 招幌与生活陈设 |
| --- | --- | --- | --- | --- |
| 驿站 | 较宽舒展，短歇山灰瓦与弯曲轻扬檐；前廊出檐较深，檐面完整、木构维护较好 | 两只暖白椭圆灯笼，分挂前廊两端或双门左右，左右高度基本一致 | 双扇木门配布帘、较宽门洞，疏方格窗，浅土墙配木柱，低石阶 | 屋侧木杆挂“酒”字长布幌，横匾保留驿站身份；门旁短凳、水缸、行囊箱，表现驿站兼酒肆的生活气氛 |
| 军营 | 端正紧凑，陡坡高脊暗灰瓦与直檐；主屋略高但不做宫殿，檐下横梁清楚 | 方形素军灯，挂门侧立柱或檐下，数量少、排列规整 | 宽实木门配厚木门框，门楣上方放交叉刀剑门饰；窄直棂窗，素土墙与灰砖基座，平直台阶 | 赭色军旗、木桩、兵器架或操练器物；交叉兵器只占门楣范围，保留教头、门洞和训练空间 |
| 铁匠铺 | 主屋偏低，不对称灰瓦屋顶加低木板附棚；旧瓦局部补修、棚梁外露，左右檐口高度不同 | 单只铁框工作灯，挂在附棚梁下靠工作台一侧，与炉火位置错开 | 敞开门面，少窗或高窄窗，近炉墙体局部烟熏，平地工作面 | 侧梁挂铸造锤轮廓标牌，与砧台、火炉、钳锤、木炭筐呼应；不以通用文字横匾代替可见工作区 |
| 民居 | 低矮错落，朴素旧瓦，侧屋或短棚可局部茅草；短檐和轻微补修 | 单只小圆赭红灯，偏挂窄门旁或短檐一侧 | 窄单门、半卷竹帘，木百叶或竖棂窗，浅土墙，单级旧石阶 | 小柴垛、竹筐、陶缸或晾晒杆；陈设少且自然，不像营业铺面 |
| 马厩 | 轻而低的单坡茅木棚，木板与茅草接合清楚，较长露梁和开放侧面 | 长形竹编防风灯，挂侧梁或入口栏柱，避开马头和中央通道 | 两个开敞木栏口，无封闭双门；栏木、饲槽、平土地面，少台阶 | 草束、水槽、缰绳与马具；两匹马和人物上马通道必须完整可见 |

“酒”字幌、铸造锤标牌、交叉刀剑门饰是首城明确的功能识别点。其悬挂杆、绳环、门框须连接到梁柱，三者在外形和挂法上也应不同。字牌由引擎排字，锤与刀剑可由独立图形绘制；不得用生成乱码或表情符号代替。驿站挂酒幌只补充店面气氛，仍提供既有驿站服务，不据此增加第六栋酒馆或售酒玩法。

城门、国槐和巨石属于公共地标，轮廓应与以上五屋形成区别。城门不作为第六栋新增功能建筑；城墙古朴低调，巨石的形状和旧驿道的露出关系应提示探索。国槐以自然树冠和树干为重，不能用浓密树叶藏住NPC或道路。

## 4. 比例与街巷

以游戏中的人物和马匹为尺，采用火红／叶绿式小镇可读性，不照搬真实建筑米制比例。首城普通房屋墙基宽度约128—144像素，开敞马厩约166像素；屋檐显示在此基础上两侧合计外伸18像素，是当前迭代的起点。具体宽高以地图实现和实机画面为准，不因图集源分辨率大就放大建筑。

- 一眼可见屋顶形状、入口和门前人物；房屋高度变化小于用途差异带来的轮廓变化，不用突然增高数倍的建筑抢焦点。
- 门旁留出站立、对话和转身位置；驿站、军营、铁匠前的服务NPC必须容易接近。
- 保持三条街与现有五处设施的联系。街边可用少量凹凸、植被、短台阶和附棚打破整齐，但主路线不可因装饰变成狭缝。
- 骑马经过道路、出城口和马厩时不被新增陈设阻挡；马厩开口与巨石后的隐藏路按实际碰撞和通行条件检查。
- 建筑背后的屋顶、灯具和树冠遵守同一遮挡规则。调整显示尺寸时同时核对落地位置、墙体、交互点与排序，不能仅靠贴图覆盖碰撞问题。

## 5. 地形、植被与市井细节

地形与建筑使用同一古城画面语言：暖土街道、旧石板铺路、灰土路肩、低饱和草地与草岸、木石公共器物。大面以平静色块为主，细节集中在路缘、墙根和功能点周围。

| 地形或景物 | 制作要求 |
| --- | --- |
| 土路 | 中间略平整、边缘少量草土变化，色差温和；保留三条街的连续性 |
| 石板 | 用有限的块面与接缝表达，不给每块石头画强高光；与土路有过渡 |
| 草地与草岸 | 草簇分布疏密变化，优先放边缘；主体色不比人物更亮、更饱和 |
| 树木 | 国槐及适合城镇的树种以树冠大形和树干可读性为先；允许高低、偏冠和枝干差异，避免复制成同一排圆球 |
| 墙根与边角 | 少量苔痕、草丛、散石、修补，聚集在合理位置；可走区和障碍的对比需要明确 |
| 水岸与桥码头 | 后续按关卡需要引入温和水色、自然岸线、简桥和小码头；首城不为凑齐参考元素而扩大地图 |
| 公共器物 | 路灯、告示、车辙、摊担和木凳可少量出现，每处有用途；不遮住对话提示和任务路线 |

不采用强写实照片纹理、显眼重复花纹、通篇发光粒子或整片密集草尖。地形自然变化不改变二维俯视路线，也不将城池改成等距斜视透视。

## 6. 资源制作与接入

建筑正式资源放在`Source/City/<城名>`，地形放在`Source/Terrain`或由对应地图的TileMap表现层组合，风格参考与本指南放在`Source/StyleGuide`。生成原图保留，新版本另存；提示词、图集格序、分辨率、透明状态和采样方式写入`Demand/美术`记录。

槐安城图集延续三列两行：驿站、军营、铁匠、民居、马厩、国槐。本轮接入版本为`Source/City/HuaiAn/huai-an-buildings-qingming-v2.png`，v1保留用于追溯。新增灯笼、檐棚和招幌时为悬出部件留足透明边距，不伸入邻物；实际取样边界不能把灯穗或屋檐裁掉。v2的部分檐角越过平均分格线，`CityArtAtlas`需先用各物体独立的自定义窗口隔开相邻内容，再按透明边界收紧；禁止直接按六个等大方格裁切。窗口数值及最终接入状态见生成记录。灯具若已包含在纹理里，代码不得再叠加同一盏。

图片只描述外观。建筑落地基准、物理足迹、NPC位置和交互范围分别由场景参数管理；更换图片不修改任务、成长、骑乘速度或存档结构。资产展示图必须能对应到真实场景，不能以整体背景图代替可交互地图。

生成时应在同一批提示里明确五屋各自的屋顶、灯具、门面和陈设，并重复共同透视、比例、色彩和光照。先保证大形，后补细节；若画面已足够识别，不继续堆叠装饰。

### 城镇坐骑的可读性（2026-10-14补充）

首城两匹马保持小尺度、暖土与灰青色系，并各自拥有可辨的毛色、鬃毛轮廓、斑纹与鞍具。枣红马较壮，长披鬃、白额白袜、赭红方毯与行旅皮囊；青骢马较瘦，短竖鬃、臀部浅斑、青色尖角鞍毯与轻装。差异不能仅靠整体换色。轮廓与中等尺度色块优先，不堆密集毛发纹理。

两马共用小跑动作，远近腿分层，支撑落蹄与回摆抬蹄清楚，马背起伏克制且与骑手同步；正常缩放移动时也要能辨认四肢和马具。本轮沿用原生几何绘制与左右侧身镜像，不生成或覆盖PNG；外观资源与190/250移速分别配置，具体记录见`Demand/Prompt/2026.10.14-骑马步态清晰度与独立外观.md`。

## 8. 洞窟与暗处探索

洞窟延续二维俯视、小尺度角色比例和暖土／灰青／低饱和绿的工程色板，地面用暖灰土、旧石板，岩壁用灰青块面，墙根仅有少量灰绿潮痕；木支架与石壁龛体现旧驿道使用痕迹。避免霓虹矿晶、哥特尖拱、写实岩石照片和高密度裂纹。岩室可有削角和转折，视觉岩壁、通行边界及遮光保持一致，连接通路保留足够宽度。

按用户最新要求，**洞窟环境明显变暗**，这是城镇昼光规范之外的场景差异。首次进入墙上蜡烛全未点燃，洞口只留小片微光；必须拥有并主动使用火把，才能逐盏点亮附近区域。火把随身光小于壁烛固定光，未点亮区域继续昏暗，岩壁挡光；火焰与HUD清楚，光源重叠避免角色过曝。每盏蜡烛独立，不能以全屏提亮替代局部照明。

当前旧驿道洞窟采用原生TileMap、块面岩壁与独立火焰表现，没有新增或覆盖角色、建筑PNG。实机截图与亮度对比见 `Build/cave`，原始需求见 `Demand/Prompt/2026.10.14-洞窟火把与分区照明.md`。
