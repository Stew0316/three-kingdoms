# 城池与地形风格指南

版本：2.0。更新日期：2026-10-17。适用范围：本项目人物、动物、动作、建筑、城池、地形、洞窟与公共景物。文件名保持不变，继续作为每次任务的必读入口。

## 阅读与使用

每次任务先阅读本指南，再按实际工作范围遵守适用章节；纯数值、战斗逻辑等工作无需为此改动美术。用户最新明确要求优先，视觉方向变化同步本指南与 `Demand` 记录；`AGENTS.md` 仅在用户明确改变长期规则或根级目录职责时更新，不跟随具体素材和参数变化。

本指南定义制作目标，不证明候选图已经接入，也不证明现有图像或动作已经通过验收。当前资产版本见 [美术资源索引](../README.md)，实现状态见 [当前实现索引](../../Demand/Content/ImplementationIndex.md)。历史 `S0` 草样与旧需求保留追溯。

## 1. 三国时期的整体方向

2026-10-24 用户明确补充：**所有新生成或重绘的图片以古朴、冷酷风为主。** 以厚重、克制的铁、铜、石、木和织物质感，沉稳明暗与自然风化表现这一方向；自然景物使用低饱和、可信的树形与枝叶。黄色玉玺和技能气焰等功能强调色可保留，但不扩大为全画面的艳丽装饰。此规则不自动要求重绘全部旧资产。

**整体色调、建筑风格、人物衣物和生活器物以三国时期为依据；所有人、动物与物件的动作必须自然，观感能对应现实对象，建筑的结构与材料也须可信。**

设计具体形制时结合三国时期及其相承的汉末文化、身份、地域、用途和材料条件确定，不把后世建筑、服饰或装饰因为“像古风”就直接当作三国式样。查证过的史料依据与游戏化设计分别记录；未确认的年代归属不能写成历史事实。既有武将身份和传说表达可保留，但需要说明哪些是游戏设定。

《清明上河图》保留为历史城市场景生活感的辅助参考，不再决定本项目的时代风格；其宋代形制不能直接作为三国建筑依据。《宝可梦 火红／叶绿》仅辅助道路、入口和地图组织的游戏可读性，不要求照搬人物头身比或牺牲自然比例。其他作品同样只参考明确的表现问题，不混合它们的年代设定与资产。

| 方面 | 统一要求 |
| --- | --- |
| 视角 | 二维俯视，屋顶和立面关系统一；保持 TileMap、八方向移动与即时战斗，建筑和器物使用同一观察高度。 |
| 比例 | 人、马、门窗、器物之间有可信尺度。地图可以压缩距离和建筑进深，但不把门、墙、屋顶缩成无法解释的结构。 |
| 配色 | 从土、石、瓦、木、铁、铜、麻、丝和染色衣料的材料关系建立色板；环境沿用暖土、木褐、灰青与自然草绿基础，衣甲、标识和灯火按身份、用途与光照变化。 |
| 造型与细节 | 大结构成立后精修材质、连接、纹样、磨损和生活痕迹；需要细致才能自然、好看的部位应精细制作，不设统一数量或密度上限。 |
| 光照 | 同场景光向、材质受光和遮挡一致；明暗变化服从场景环境，角色、入口和交互点清楚。 |
| 画面层次 | 细节可以丰富，仍需在实际游戏缩放下分辨人物、道路、危险范围和可交互物。控制干扰信息，不以删去所有细节解决噪声。 |
| 生活与用途 | 服饰穿法、工具使用、建筑空间和器物摆放有用途；连接、接触、承重和磨损位置能被解释。 |

## 2. 自然动作的统一要求

动作要有真实对象的结构和运动依据，包括待机、走跑、起停、转身、持械、攻击、受击、闪避、倒地、上下马、骑乘，以及门、旗幡、灯具和其他活动物件。游戏允许调整速度和幅度，但运动的因果关系要成立。

- 人体动作检查重心、支撑脚、髋肩传递、关节活动范围和惯性。腿脚承重与身体位移对应，停下有收势，顶墙后不能原地循环赶路步态。
- 持械动作检查握点、手腕、肘肩和武器重量。手握在可握的位置，双手协同，蓄势、出手、命中、收招连续；武器不能靠突然跳位或穿过身体完成换姿。
- 动物动作按对应物种建立骨架、步态、落地与腾空次序。马的前后肢、肩髋、脊背、颈头和尾部相互协调，不能把四肢作为彼此独立的摆杆。
- 骑手和坐骑有连续接触关系：骨盆跟随鞍座，腰髋与胸肩吸收起伏，手执缰、脚踩镫；不同部位有合理的相位和幅度，不整体僵硬平移。
- 衣物、披风、冠翎、鬃尾和悬挂物依附明确，随重力、惯性、风或接触变化。使用关键帧、程序求解或物理模拟由效果和成本决定，不预先禁止某种精细实现。
- 正常速度和实际游戏尺寸用于判断整体自然程度；慢放、逐帧和骨骼调试用于核对接地、关节、穿插和时序。可读性与动作真实性都要验收，不能用一种遮盖另一种缺陷。

现有角色、马匹与骑乘的具体参数和已知限制放在对应需求及实现文档，不能把某次试调角度或步态相位当作所有对象的统一规范。

## 3. 建筑的结构与用途

每栋建筑先确定用途、尺度、材料和空间关系，再制作外形。相邻建筑应在屋顶、入口、附属空间中形成清楚差异，并结合窗、灯具、招幌和陈设表达身份，避免同一模型仅换色。

| 部位 | 制作要求 |
| --- | --- |
| 屋顶与檐口 | 屋脊、坡面、檐口和支撑关系完整，材料有重量；出檐连接梁柱或托撑，不能悬空。形制按三国依据核对。 |
| 梁柱、墙与基座 | 柱、梁、墙、地基的落点与传力关系合理；土木、瓦石的连接和修补有原因，不用纹理掩盖结构断裂。 |
| 门窗与台阶 | 门可供对应人物或物件进出，门槛、室内地面、台阶和道路高差连贯；窗格的密度按用途、尺度和材质确定。 |
| 灯具与悬挂 | 灯具种类、数量、材质和挂点按用途与时代依据选择；绳、杆和支点连接清楚，避开必要的通行空间。 |
| 招幌与标识 | 形状、材质和安装方式表达功能；文字由引擎清楚显示，不使用生成乱码。商业招幌或特殊门饰的年代不明时记录为游戏化设定。 |
| 材质与使用痕迹 | 瓦缝、木纹、金属连接、织物、烟熏、潮痕和磨损可精细制作；分布与制作方法、受力和使用行为对应。 |
| 生活陈设 | 工具、柴草、筐缸、车马和家具按空间用途摆放，既有生活感也能留下实际工作、交互和行走的位置。 |

普通建筑与特殊地标的等级、规模和装饰有身份依据，不能为了显眼把普通设施变成无法解释的宫殿。新增细节不得遮住 NPC 或制造视觉门口与碰撞墙体不一致的问题。

## 4. 槐安城现有五屋的接续

首城保持三条街、五栋建筑、五名 NPC 的当前可玩规模。本表保留已接入资产的识别设计，便于后续制作衔接；这些具体屋顶、灯具和招牌组合源于 2026-10-13 的版本，**不是三国历史形制已经核实的结论**。后续重绘先按本指南核对时期和结构，再保留或调整功能识别。

| 建筑 | 现有识别设计 | 后续制作必须保持的用途关系 |
| --- | --- | --- |
| 驿站 | 曲檐短歇山、前廊、暖白椭圆灯、侧挂“酒”字幌 | 清楚的接待入口、休息与整备空间；酒幌属于表现设定，不增加第六栋酒馆或售酒系统。 |
| 军营 | 陡高脊直檐、方灯、厚木门框与交叉刀剑门饰 | 出入、训练、武器存放和教头站位合理；兵器装饰与梁柱连接可信。 |
| 铁匠 | 不对称瓦顶与木板附棚、铁框灯、锤形标 | 敞开工作面、炉火、砧台和工具配合，烟熏与通风有依据。 |
| 民居 | 旧瓦与茅草侧棚、单圆灯、窄门与生活器物 | 体现居住、储物与日常使用，入口和窗墙比例自然。 |
| 马厩 | 单坡茅木棚、双敞栏、竹编长灯、饲槽与草束 | 马身、马头、转身和上马空间足够；饲槽、缰绳与栏木符合实际使用。 |

城门、国槐、巨石属于公共地标，不计为额外功能建筑。树干、树冠、城墙和道路保留合理遮挡；巨石与旧驿道的露出关系应能提示探索。

## 5. 地形、街巷与自然景物

土路、石板、路肩、草岸、树石和公共器物与建筑使用一致的材质、色调和光照。地面可有丰富细节，分布须符合行走、排水、堆积、植物生长和长期使用的逻辑；实际画面上不能与人物和交互提示争夺辨识。

| 内容 | 制作要求 |
| --- | --- |
| 路与石板 | 通行方向连续，路缘过渡自然；石板铺设、接缝、高差和磨损可信。 |
| 草地与水岸 | 草木疏密、岸线与潮湿变化有环境依据，植物不遮住应当可见的道路边界。 |
| 树木 | 树冠、主干、枝条和根部连贯，允许自然偏冠与高低差；遮挡区域与实际通路一致。 |
| 公共器物 | 告示、车辙、摊担、灯具、桥与码头按关卡用途设置，支撑结构、操作空间和落地点完整。 |
| 交互与碰撞 | 屋门、NPC、马厩、城门、巨石及隐藏路容易定位且可达；移动体积、遮挡和碰撞同步核对。 |

地图可以按玩法压缩距离，但不能靠整体背景图替代实际可走地图，也不能为塞进陈设把主路线变成无法通行的缝隙。

## 8. 洞窟与暗处探索

洞窟延续二维俯视比例，岩壁、土石道路、木支架和壁龛使用可信的自然结构与三国行旅环境。岩石层理、裂隙、潮痕和支护可精细制作，照明下仍能辨认地面、墙体与通路；视觉岩壁、碰撞和遮光边界一致。

洞窟环境明显变暗。首次进入壁烛未点燃，洞口留有微光；拥有并主动使用火把后可以逐盏点亮附近区域。随身火把光小于壁烛固定光，未点亮区域继续昏暗、岩壁挡光；光源叠加不能让角色过曝。每盏壁烛独立保存状态，不能以全屏提亮代替局部照明。

当前实现与截图记录见 [洞窟内容](../../Demand/Content/OldRoadCave.md)及 [洞窟需求](../../Demand/Prompt/2026.10.14-洞窟火把与分区照明.md)，本轮没有重绘洞窟或角色资产。
